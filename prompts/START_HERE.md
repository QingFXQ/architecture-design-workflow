# 可转发的智能体启动提示词

下载仓库并告诉智能体本地位置；也可让具备联网与文件能力的智能体按下面提示词取得仓库。已有项目填当前断点，不必重新设计。

```text
请使用 https://github.com/QingFXQ/architecture-design-workflow 的建筑设计工作流，协助我完成建筑设计项目。先将仓库读取到可访问的本地目录（已有则直接使用），依次读 README.md、AGENTS.md、workflows/PIPELINE_WORKFLOW.md，再按 docs/SKILL_LIBRARY.md 选读当前任务相关技能，不要一次加载所有资料。

项目目录：[填写]
任务书与场地资料：[填写路径，或随后提供]
已有模型／图纸与当前进度：[填写；没有则写从零开始]
本次目标与截止：[填写]
必交成果、纸幅／张数／比例、风格：[填写；未知请登记]
可用软件与连接：[填写；不知道则先只读检查]
已经确定、不能擅自改变的内容：[填写]

先读真实资料和项目记录，只读确认软件、活动文件和版本，判断从哪个阶段接续；缺信息但不影响当前工作的部分先推进，只集中询问阻碍下一步的关键问题。新项目维护简短 PROJECT.md 和 BRIEF.md，已有项目沿用记录。

在授权范围内连续完成实际研究、设计、建模、工程图、表现与交付，不停在计划。Blender／SU 全程可用，Revit／CAD 按项目选择。优先结构、功能、主流线与空间审美；先核单位、尺寸、场地及面积口径。工程制作先做代表样板，实际看平剖／三维后扩展。同一活动模型一个写入者，重要变更可恢复。

先看排版参考并核实际纸面容量，再制作需要的分析图，最后同版输出并渲染检查 PDF。AI 表现保持模型几何；未完成、估算与已核实内容分清。不复制别的项目的身份、尺寸、纸幅或本机路径。缺软件连接时先做独立准备并说明限制，不宣称完成未做操作。用几句话说明当前起点，然后开始执行。
```
