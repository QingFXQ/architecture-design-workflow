# C01｜社区公共中心 / 图书馆

- 建筑面积：3,200 ㎡；城市街角，南临生活性街道，西临公园和开放广场。
- 功能：安静阅览、儿童阅读、青少年工坊、多功能活动厅、社区教室、咖啡/服务台、小型展览、管理、图书/物料后勤、卫生间与设备。
- 运营：活动厅、咖啡、卫生间和一间社区教室须可夜间独立开放；安静阅览区在夜间关闭；后勤从东侧小巷进入，不穿越公共大厅。
- 关键矛盾：开放街道/公园界面与安静阅读并存，不同年龄使用者可共享但不互相压制，多时段运营不依赖临时封堵。

## 模拟 Gate A 决策

选择“西南公共门厅/室外台阶 + 可独立关闭的夜间公共带 + 北侧安静阅读庭院”方向。

**Must preserve：** 街角和公园都可识别进入；夜间公共带不穿越安静阅览；后勤独立；室内外公共活动形成连续门槛而非纯玻璃盒子。

**Adjustable：** 中庭是否完整贯通、儿童区与青少年工坊的上下层关系、阅读庭院尺度及咖啡位置。

## 必答

至少两个方案变体；分别画出日间公众、夜间公众、儿童、工作人员/后勤、疏散路径，并说明噪声、门禁、可变空间与室内外边界的验证方法。
