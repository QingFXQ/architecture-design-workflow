## 1 层高（GB 50352-2019 第 5.2 节）

### 1.1 基本定义

- **层高**：楼地面（完成面）到上一层楼面完成面的垂直距离（5.2.1）
- **净高**：楼面完成面到顶棚底面或梁底的垂直距离

### 1.2 各类建筑层高建议值（附录 / 引用专业规范）

| 建筑类型 | 层高推荐 | 备注 |
|---|---|---|
| 住宅 | 2.8–3.0m（常见 3.0m） | 卧室、起居室净高 ≥ **2.40m**（GB 50352-2019 5.2.5 引用住宅设计规范） |
| 办公 | 3.0–3.6m（净高 ≥ 2.70m） | 《办公建筑设计标准》JGJ/T 67-2019 |
| 学校教室 | 层高 ≥ **3.30m**（GB 50099-2011 要求） | 详见 07-school.md |
| 幼儿园活动室 | 层高 ≥ **3.30m**（JGJ 39-2016） | 详见 06-kindergarten.md |
| 图书馆阅览室 | 净高 ≥ **2.40–2.80m**（JGJ 38-2015） | 开架阅览更高 |
| 商业营业厅 | 净高 ≥ **3.00m**（常见 3.5–4.5m） | — |
| 医院病房 | 净高 ≥ **2.80m**（JCI 医院标准 3.0m） | — |
| 地下机动车库 | 净高 ≥ **2.20m**（微型车 2.0m，小车 2.2m） | 详见 GB 50067 车库规范 |
| 走道、楼梯间 | 净高 ≥ **2.10m**（5.2.5 注） | 局部净高 ≥ 1.90m 时，净高不足段长度 ≤ 走道长度的 1/2 |

> 标记：**硬性规定**（净高 2.10m 来自 5.2.5，**强条**）。其余建筑类型净高为"专业规范 + 通用规范"双重规定。

### 1.3 地下室、半地下室定义（GB 50352-2019 2.0.4、2.0.5）

| 类型 | 定义 | 设计含义 |
|---|---|---|
| **地下室** | 房间地面低于室外设计地面的平均高度大于该房间平均净高 1/2 的房间 | 防火分区面积 500 m²、严防火 |
| **半地下室** | 房间地面低于室外设计地面的平均高度大于该房间平均净高 1/3 且不大于 1/2 的房间 | 防火分区面积、疏散均较严 |
| 普通楼层 | 地面低于室外地面的高度 ≤ 净高 1/3 | 按正常楼层 |

> **方案要点**：地下室与半地下在防火分区面积、疏散距离、采光通风、防水要求均不同。半地下常因可设开窗改善采光通风被采用，但防火严于普通楼层。

## 2 楼梯（GB 50352-2019 第 6.7 节）

### 2.1 踏步尺寸

- **踏步高（h）**：**≤ 0.16m**（公共建筑、住宅室内，6.7.3）
- **踏步宽（b）**：**≥ 0.28m**（公共建筑、楼梯专用，6.7.3）；住宅套内可放宽至 **≥ 0.26m**
- **2h + b = 0.60–0.64m**（步距公式，常用 0.63m）
- 常见组合：h=0.15m × b=0.30m（住宅、办公）；h=0.16m × b=0.28m（公共）；h=0.13m × b=0.26m（幼儿园，JGJ 39 加严）
- **楼梯梯段净宽**：公共建筑 ≥ **1.20m**，住宅 ≥ **1.10m**（详见 01-gb55016-fire.md 与 10-stairs-circulation.md）

### 2.2 平台宽度

| 平台类型 | 最小宽度 |
|---|---|
| 中间平台（梯段之间） | **≥ 梯段净宽**（且 ≥ 1.20m） |
| 顶层平台（通至楼面） | **≥ 梯段净宽**，且当门下时 ≥ **门宽 + 0.40m** |
| 底层平台（通出入口） | **≥ 梯段净宽**，且 ≥ **门洞宽 + 0.40m** |

- 来源：GB 50352-2019 6.7.5、6.7.6
- 标记：**硬性规定**

### 2.3 楼梯井与梯井宽

- 相邻两梯段（平行梯）之间的梯井宽度：**≥ 0.11m**（防止儿童坠落）；**> 0.11m 时必须设防护**（6.7.7）
- 标记：**硬性规定**（住宅、幼儿园、学校**强制**）

### 2.4 楼梯踏步防滑与构造

- 踏步面层应防滑（公共建筑 ≥ R10；幼儿园、学校、医院 ≥ R11）
- 梯段间高差处理：**不应有高度 ≥ 0.20m 的高差**无警示
- 踏步突缘：**≤ 0.02m**（防止绊倒）

## 3 栏杆、栏板、扶手（GB 50352-2019 第 6.6 节）

### 3.1 栏杆高度（**强条**，方案必查）

| 部位 | 栏杆（栏板）高度 |
|---|---|
| 临空高度 < 24m（住宅、宿舍、旅馆、办公楼、医院、托幼等） | **≥ 1.05m** |
| 临空高度 ≥ 24m（含中高层、高层） | **≥ 1.10m** |
| 临空高度 ≥ 100m（超高层，GB 55037-2022 引用） | **≥ 1.20m** |
| 室外楼梯 | **≥ 1.10m** |
| 上屋面楼梯 | **≥ 1.20m**（且与屋面女儿墙栏杆同等高度） |
| 幼儿园、托儿所 | **≥ 1.10m**（且**不可设横向栏杆**，JGJ 39-2016 加严） |
| 中小学校 | **≥ 1.10m**（且**不可设横向栏杆**，GB 50099-2011 加严） |

> 来源：GB 50352-2019 6.6.3（强条）。
> 标记：**硬性规定**（**全文强制性**条文，方案必查）。

### 3.2 栏杆竖向间距

- 栏杆间距：**≤ 0.11m**（6.6.4，防止儿童坠落，**强条**）
- 幼儿园、中小学校：**严禁**设横向栏杆；可踏面（花池、家具等）距栏杆顶距离 ≥ 0.45m
- 玻璃栏杆应使用**夹层玻璃**（公称厚度 ≥ 12mm 钢化夹层或 ≥ 16mm 夹层玻璃，6.6.5）

### 3.3 扶手高度与连续性

- 扶手高度：从踏步前沿线量起，**≥ 0.90m**（6.6.7）；楼梯水平段或顶层平台 ≥ **1.05m**
- 高层建筑楼梯扶手：**≥ 1.10m**（含水平段）
- 楼梯水平段栏杆长度 **> 0.50m** 时，扶手高度应 ≥ **1.05m**（防儿童攀爬）
- 扶手连续：楼梯段两端扶手**贯通**，顶层平台转角处与相邻梯段扶手**连续**
- 双层扶手（无障碍、儿童双高度）：下层 **0.60–0.65m**，上层 **0.85–0.90m**（详见 03-gb50763-accessibility.md）

### 3.4 公共楼梯扶手承重

- 扶手水平荷载：**≥ 1.5 kN/m**（住宅 0.5 kN/m，公共 1.0 kN/m）
- 顶部栏杆水平荷载：**≥ 1.5 kN/m**
- 来源：GB 50352-2019 6.6.8（结构计算条目，方案阶段需在结构说明中提及）

## 4 窗台高度（GB 50352-2019 第 6.11 节）

### 4.1 临空窗台

| 位置 | 窗台高度（完成面） |
|---|---|
| 普通住宅、宿舍、旅馆、办公楼 | **≥ 0.90m**（6.11.4，**强条**） |
| 托儿所、幼儿园 | **≥ 1.20m**（JGJ 39-2016 加严） |
| 中小学校 | **≥ 1.10m**（GB 50099-2011 9.1 节） |
| 公共建筑（商场、车站等） | **≥ 0.85m**（防坠落） |
| 外廊、内天井 | **≥ 1.10m**（同栏杆） |

> 标记：**硬性规定**。低于限值的窗户应设防护栏杆（窗台栏杆）或固定扇。

### 4.2 落地窗（GB 50352-2019 6.11.6）

- 落地窗台面（室内完成面）与室内地面高差 **≤ 0.50m** 时，必须设防护栏杆
- 落地窗护栏高度同栏杆（6.6 节）
- 玻璃落地窗必须使用**安全玻璃**（6.11.6）

## 5 走廊与走道（GB 50352-2019 第 6.4 节）

### 5.1 走廊净宽

| 部位 | 最小净宽 |
|---|---|
| 单面房间走廊（公共建筑、住宅、办公） | **≥ 1.30m**（含 1.30m） |
| 双面房间走廊（公共建筑、办公） | **≥ 1.50m** |
| 医院病房走廊（单排） | **≥ 1.50m**（GB 51039 综合医院 5.6 节） |
| 医院病房走廊（双排） | **≥ 1.80m** |
| 住宅走廊（套内过道） | **≥ 1.00m**（卧室、起居室过道，常见 1.10–1.20m） |
| 幼儿园走廊 | **≥ 1.80m**（活动走廊） / **≥ 1.50m**（普通走廊） |
| 中小学校走廊（外廊） | **≥ 1.80m**（内廊 2.10m，GB 50099-2011） |
| 无障碍走廊 | **≥ 1.50m**（详见 03-gb50763-accessibility.md） |

> 标记：**硬性规定**（GB 50352-2019 6.4 节）。
> 注：上述部分走廊宽度源自各专业规范（如 GB 50099、JGJ 39），GB 50352 给兜底值，专业规范更严时按专业规范。

### 5.2 走廊净高

- **≥ 2.10m**（同楼梯净高）
- 局部净高不足 2.10m 的区段，长度 **≤ 走廊总长 1/2**

## 6 净高（GB 50352-2019 第 5.2 节汇总）

| 部位 | 净高下限 |
|---|---|
| 住宅卧室、起居室 | **≥ 2.40m** |
| 厨房、卫生间（住宅） | **≥ 2.20m** |
| 办公空间 | **≥ 2.70m**（净高） |
| 教室（中小学） | **≥ 3.10m**（层高 3.30m） |
| 走廊、楼梯、卫生间 | **≥ 2.10m** |
| 坡道（净高） | **≥ 2.10m** |
| 地下车库 | **≥ 2.20m**（微型 2.0m） |
| 避难空间 | **≥ 2.10m**（**强条**） |
| 商业营业厅 | **≥ 3.00m**（基本要求，专业规范可上浮） |

> 来源：GB 50352-2019 5.2.5（强条） + 各专业规范。
> 标记：**硬性规定**。

## 7 地下室与半地下室

### 7.1 采光通风（GB 50352-2019 5.3 节）

- 半地下室可设采光通风窗（高出室外地面 0.50m 以上有采光井可通风）
- 地下室需机械通风、防潮、防渗
- 地下室防水等级：一级（最高）/ 二级 / 三级 / 四级（GB 50108 地下工程防水技术规范）
- 住宅、托幼、老年人照料**不应**设地下室、半地下（住宅卧室、起居室，6.5.1；托幼 3.1.4）

### 7.2 疏散

- 地下室、半地下室的疏散楼梯间**严禁与地上楼梯间共用**（防火分区隔开，GB 50016-2014 6.4.4）
- 地下室防火分区面积：**500 m²**（详见 01-gb55016-fire.md）
- 出入口：**独立直通室外**（与地上隔开），数量 ≥ 2

## 8 室内外高差与首层出入口

### 8.1 室内外高差（GB 50352-2019 4.1 节）

- 一般建筑：**0.15–0.30m**（防雨水倒灌）
- 老年人照料设施、医疗建筑：**≤ 0.15m**（无障碍优先）
- 半地下室、半地下室：满足"半地下室"定义即可（净高 1/3 与 1/2 之间）

### 8.2 入口防风雨、防滑

- 主要出入口设雨篷（常见 1.5–3.0m 出挑）
- 室内外高差通过**台阶 + 坡道**同时解决（无障碍要求，详见 03-gb50763-accessibility.md）
- 地面防滑等级：医院、托幼、老年人建筑**R10**以上

## 9 围护结构热工（GB 50352-2019 5.5 节）

### 9.1 节能底线

- 执行 GB 55015-2021《建筑节能与可再生能源利用通用规范》
- 严寒、寒冷地区：外墙 K ≤ 0.30–0.40 W/(m²·K)，屋面 K ≤ 0.20–0.30
- 夏热冬冷、夏热冬暖：K ≤ 0.80–1.20，遮阳系数 SC ≤ 0.3–0.5
- 公共建筑节能：**K 值、SHGC、可见光透射比**按 GB 55015-2021 第 4 章执行
- 来源：GB 50352-2019 5.5.1 + GB 55015-2021

### 9.2 玻璃幕墙（GB 50352-2019 5.5.4）

- 玻璃幕墙可见光反射比 **≤ 0.30**（防光污染）
- 玻璃幕墙气密性等级 ≥ **3 级**（GB/T 21086）
- 防火：每层楼板处设**耐火 1.0h**的防火封堵（GB 50016-2014 6.2.7）

## 10 方案设计自查清单（GB 50352）

1. ☐ **层高**是否满足专业规范最低值？住宅 2.8m、办公 3.0m、教室 3.3m
2. ☐ **净高**：卧室 2.40m、办公 2.70m、走廊楼梯 2.10m、地下车库 2.20m
3. ☐ **地下室定义**：净高 1/2 是分界线，半地下 1/3–1/2
4. ☐ **楼梯踏步**：h ≤ 0.16m，b ≥ 0.28m，2h+b = 0.60–0.64m
5. ☐ **平台宽度**：≥ 梯段净宽，门下加 0.40m
6. ☐ **栏杆高度**：< 24m 1.05m，≥ 24m 1.10m，超 100m 1.20m
7. ☐ **栏杆间距** ≤ 0.11m；托幼、中小**禁横向栏杆**
8. ☐ **扶手高** ≥ 0.90m，水平段 ≥ 1.05m
9. ☐ **窗台高** ≥ 0.90m（公共 ≥ 0.85m，托幼 ≥ 1.20m，中小学 ≥ 1.10m）
10. ☐ **走廊净宽**：单面 1.30m，双面 1.50m（医院 1.80m）
11. ☐ **走廊净高** ≥ 2.10m
12. ☐ **室内外高差** 0.15–0.30m，且同时设台阶与坡道
13. ☐ **栏杆水平荷载** ≥ 1.5 kN/m 在结构说明中标注

## 12 不确定 / 待核实条目

- **住宅室内外高差 0.15m** 与老年人照料设施、医院的具体要求差异：来自 JGJ 122 老年人照料、JGJ 49 综合医院，本笔记未引用具体条文号

- **玻璃栏杆夹层玻璃厚度** 的精确值：来自 GB 50352-2019 6.6.5，详细尺寸与 JGJ 102 玻璃幕墙协同
