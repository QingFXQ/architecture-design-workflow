## 1 博物馆分类与组成

### 1.1 类别（JGJ 66-2015 1.0.3）

按规模分类：

| 类别 | 建筑总面积 |
|---|---|
| 大型馆 | > **30000 m²** |
| 中型馆 | 10000–30000 m² |
| 小型馆 | 5000–10000 m² |
| 小型馆（最小） | < 5000 m² |

### 1.2 功能区组成（JGJ 66-2015 第 4 章）

```
博物馆 = 藏品区 + 陈列展览区 + 观众服务区 + 行政办公区 + 技术设备区 + 学术研究区
```

| 功能区 | 主要房间 |
|---|---|
| **藏品区** | 藏品库房、暂存库、缓冲间、鉴赏室、修复室、复制室 |
| **陈列展览区** | 展厅、序厅、过厅、休息厅、报告厅 |
| **观众服务区** | 售票、入口大厅、咨询、纪念品商店、餐饮、卫生间、休息区 |
| **行政办公区** | 办公、会议、档案 |
| **技术设备区** | 空调机房、配电、监控、消防、安防 |
| **学术研究区** | 研究室、图书资料、信息中心 |

> 标记：**硬性规定**（4.1 节功能分区要求）。藏品区、陈列区、观众区**必须严格分区**（**强条**，4.1.3）。

## 2 藏品区（库房）（JGJ 66-2015 第 5 章）

### 2.1 库房分区（5.1 节）

按藏品性质分：

| 库房类型 | 适用 |
|---|---|
| 文物库 | 不可再生文物（青铜、陶瓷、书画、古籍） |
| 危险品库 | 油画、动植物标本、化学品类 |
| 普通库 | 一般展品、复制品、辅助材料 |
| 缓冲间 | 藏品进入库前的过渡空间（**强条**） |

- **强条**：不同材质藏品**必须**分类分库（5.1.2）
- 标记：**硬性规定**

### 2.2 库房面积

- **藏品库房面积 ≥ 博物馆总建筑面积的 30%**（JGJ 66-2015 5.1.4，部分解读为"藏品区总面积占比"）
- 实际常见：藏品库 + 缓冲 + 修复 ≈ 总面积 25–40%
- 标记：**硬性规定**（**强条**）

### 2.3 库房层高与净高

| 库房类型 | 层高 | 净高 |
|---|---|---|
| 普通文物库 | **≥ 3.50m**（JGJ 66-2015 5.2.3） | **≥ 2.80m** |
| 大型文物库（雕塑、大型器具） | **≥ 5.00m** | **≥ 4.00m** |
| 危险品库 | **≥ 3.50m** | **≥ 2.80m**（独立设置） |
| 缓冲间 | **≥ 3.00m** | **≥ 2.40m** |

> 标记：**硬性规定**。藏品库层高是博物馆建筑最关键参数之一。

### 2.4 库房温湿度

| 库房类型 | 温度（℃） | 相对湿度（%） |
|---|---|---|
| 金属文物库 | **18–22** | **40–55** |
| 陶瓷、玻璃库 | **18–22** | **45–60** |
| 书画、古籍库 | **16–20** | **50–60** |
| 油画、壁画库 | **16–22** | **45–55** |
| 动植物标本库 | **16–20** | **45–55** |
| 普通库 | **16–24** | **45–65** |
| 缓冲间 | **12–26** | **40–70** |

> 来源：JGJ 66-2015 5.3 节 + GB/T 23863-2009
> 标记：**硬性规定**。空调设计必须满足全年稳定范围，波动 ±2℃、±5% RH。

### 2.5 库房防潮防水

- 库房**不应**设地下室（5.2.4，**强条**）——防潮、防水难度
- 库房**严禁**穿越给排水管道（5.3.6，**强条**）
- 屋面防水等级：**一级**（GB 50178 一级）
- 墙地面：防潮砂浆 + 防潮涂料，**地面承载 ≥ 8 kN/m²**（堆藏品）
- 标记：**硬性规定**

### 2.6 库房门与窗

- 库房门：**甲级防火门**（GB 50016-2014）+ 防盗门双层（**强条**）
- 库房窗：仅通风高侧窗，**严防紫外线**（夹层玻璃 + 滤光膜）
- 窗地比：**≤ 1/20**（高侧窗为主，避免自然光直射）
- 标记：**硬性规定**

## 3 陈列展览区（JGJ 66-2015 第 6 章）

### 3.1 展厅面积（6.1 节）

- **陈列区总面积 ≥ 博物馆总建筑面积的 30%**（6.1.3，部分版本为 25%）
- 大型博物馆展厅面积通常 **15000–25000 m²**
- 展厅单元面积：

| 展厅类型 | 单元面积 |
|---|---|
| 序厅（主入口大厅） | **200–500 m²**（大型馆 ≥ 800 m²） |
| 基本陈列厅 | **300–1500 m²**（大型馆 ≥ 1500 m²） |
| 专题展厅 | **100–500 m²** |
| 临时展厅 | **300–800 m²** |
| 报告厅 | **200–500 座**（大型馆 ≥ 500 座） |
| 过厅、连接厅 | **≥ 100 m²**（人流缓冲） |

> 标记：**硬性规定**（展区占比），单元面积为**常见做法**。

### 3.2 展厅净高（6.2 节）

| 展厅类型 | 净高（m） |
|---|---|
| 平面陈列厅（书画、小件） | **≥ 3.50m** |
| 通柜陈列厅（中等文物） | **≥ 4.00m** |
| 大型文物展厅（雕塑、车辆） | **≥ 5.00m**（大型馆 **≥ 7.00m**） |
| 高大空间展厅（恐龙、大型装置） | **≥ 8.00m–15.00m** |
| 报告厅 | **≥ 4.50m**（阶梯地面至顶棚） |
| 临时展厅 | **≥ 4.00m**（与基本陈列厅统一） |

> 标记：**硬性规定**（最小值）。

### 3.3 展厅层高

- 展厅层高 ≥ 净高 + 0.80–1.50m（结构、空调、灯光、吊顶）
- 大型博物馆：展厅层高 **6–12m**（含夹层）
- 净高计算点：地面完成面至顶棚底面或突出物底面

### 3.4 展厅采光（GB/T 23863-2009 + JGJ 66-2015 6.3 节）

| 类型 | 采光要求 |
|---|---|
| 自然采光展厅 | 侧窗采光 + 高侧窗（**避免直射光**，**强条**） |
| 人工照明展厅 | 全部人工照明（珍贵文物） |
| 采光等级 | **Ⅱ类**（博物馆建筑） |
| 窗地比 | **≥ 1/6**（侧窗，主要展厅） |
| 眩光限制 | **UGR ≤ 19**（展厅） |
| 紫外线滤除 | 玻璃含 UV 滤除层（透过率 ≤ 0.5%） |
| 显色指数 | Ra **≥ 90**（展厅照明，**强条**） |

> 来源：JGJ 66-2015 6.3 + GB/T 23863-2009
> 标记：**硬性规定**。UV 滤除是文物保护的硬性要求。

### 3.5 展线与展柜

- 展线长度：**≥ 文物数量 × 2.5m**（常见经验）
- 展柜类型：
  - 沿墙通柜：进深 0.80–1.20m，高 2.40m
  - 独立柜：1.50m × 0.80m × 2.50m
  - 中心柜：异形
  - 龛柜：嵌入墙体
- 展柜温湿度：**独立微环境**控制（恒温恒湿展柜）
- 展柜照明：**≤ 50 lux**（光敏文物）/**≤ 200 lux**（一般文物）/**≤ 300 lux**（无光敏）

### 3.6 报告厅（6.5 节）

- 容量：**200–500 座**（大型馆可 800–1500 座）
- 视距：最远视距 **≤ 30m**（多功能厅可放宽）
- 视线升高值：**C = 0.12m**（视高差）
- 声学：混响时间 **≤ 1.5s**（满场，500 Hz）
- 照明：可调光（**0%–100%**，会议/放映两用）

## 4 观众服务区（JGJ 66-2015 第 7 章）

### 4.1 入口大厅

- 容量：按瞬时客流计算 **≥ 1500 人/m²·h**（高峰系数 1.5）
- 净高：**≥ 6.00m**（大型馆 8–12m）
- 安检：设**安检区**（X 光机 + 安检门）+ 售票
- 寄存：设**寄存柜**（每 1000 m² 展厅 ≥ 30 个寄存柜）

### 4.2 卫生间

- 数量：每 1000 m² 展厅**男 ≥ 2 个厕位、女 ≥ 4 个厕位**
- 无障碍：**≥ 1 个无障碍厕位 / 层**
- 母婴室：**≥ 1 个**（大型馆每层一个）
- 详见 09-hotel-office.md

### 4.3 餐饮与纪念品

- 餐饮：**≥ 200 座**（大型馆 ≥ 500 座）
- 餐厅面积：**≥ 1.0 m²/座**
- 纪念品商店：**≥ 100 m²**（大型馆 ≥ 300 m²）

## 5 防火与疏散（GB 50016-2014 + JGJ 66-2015 第 8 章）

### 5.1 耐火等级

- 一级耐火（**强条**，JGJ 66-2015 8.1.1）

### 5.2 防火分区

- 展厅防火分区：**≤ 2500 m²**（GB 50016-2014 5.3.1）
- 设自动灭火 + 自动报警：可放宽至 **5000 m²**（需性能化论证）
- 藏品库：**≤ 500 m²**（从严）
- 防火分隔：展厅与藏品库**严禁**直接连通（**强条**）

### 5.3 疏散

- 安全出口：**≥ 2 个**（防火分区，GB 50016-2014 5.5.8）
- 疏散距离：GB 50016-2014 表 5.5.17，公共建筑 ≤ **30m**（一二级）/40m（高层）
- 疏散走道：净宽 **≥ 1.50m**（展厅主走道 **≥ 2.40m**）
- 楼梯：详见 01-gb55016-fire.md
- 应急照明：**≥ 1.0 lx**（展厅）/**≥ 5.0 lx**（楼梯、走道）

### 5.4 展厅特殊性

- 展厅**严禁**用**防火卷帘**作主要疏散分隔（GB 50016-2014 6.5.3）
- 建议用**防火墙**或**防火玻璃墙**分隔
- 疏散指示：连续、间距 **≤ 20m**

## 6 无障碍（GB 50763-2012 + JGJ 66-2015 第 9 章）

### 6.1 入口无障碍

- 主要出入口**必须**无障碍（**强条**）
- 坡道 + 升降台 + 自动门

### 6.2 展厅内无障碍

- 展厅主通道：**≥ 1.50m**
- 展厅门口：无门槛、高差（**≤ 0.02m**，局部设坡道）
- 轮椅观众席位：报告厅、剧场**≥ 总席位 2%**
- 详见 03-gb50763-accessibility.md

### 6.3 盲文与触觉标识

- 展厅入口、展品说明牌设**触觉地图 + 盲文**
- 触觉展品复制品（**强条**，9.3 节）

## 7 安防（JGJ 66-2015 第 10 章）

### 7.1 安防等级

| 博物馆级别 | 安防等级 |
|---|---|
| 一级风险单位（珍贵文物） | **一级安防** |
| 二级风险单位 | 二级安防 |
| 三级风险单位 | 三级安防 |

- 来源：GB/T 16571-2012 博物馆、文物建筑安防

### 7.2 安防设施

- **周界报警**：电子围栏 + 红外对射
- **视频监控**：全覆盖、无死角（**强条**），记录 ≥ 30 天
- **门禁系统**：藏品库、修复室、监控室**必须**门禁
- **入侵报警**：藏品库、展厅闭馆后启动

### 7.3 玻璃防护

- 展厅玻璃：**夹层玻璃**（防砸、防弹）
- 展柜玻璃：**≥ 6+6 mm 夹层玻璃**（贵重文物 ≥ 8+8 mm）

## 8 方案设计自查清单（博物馆）

1. ☐ **藏品区占比 ≥ 30%**，**陈列区占比 ≥ 30%**
2. ☐ **藏品库层高**：普通 ≥ 3.50m，大型 ≥ 5.00m
3. ☐ **藏品库净高** ≥ 2.80m（普通） / 4.00m（大型）
4. ☐ **库房温湿度** 按文物材质分类（金属 18-22℃/40-55%）
5. ☐ **库房严禁穿越给排水管道**（**强条**）
6. ☐ **库房不应设地下室**（**强条**）
7. ☐ **展厅净高**：平面 ≥ 3.50m、大型 ≥ 5.00m、超大 ≥ 8.00m
8. ☐ **展厅窗地比 ≥ 1/6**，UV 滤除
9. ☐ **照明显色指数 Ra ≥ 90**
10. ☐ **防火分区 ≤ 2500 m²**（展厅）/500 m²（藏品库）
11. ☐ **耐火等级一级**（**强条**）
12. ☐ **展厅与藏品库严禁直接连通**（**强条**）
13. ☐ **主要入口 + 展厅通道**无障碍
14. ☐ **安防等级**：一级风险单位（珍贵文物）
15. ☐ **报告厅视距 ≤ 30m**，混响 ≤ 1.5s
16. ☐ **男女厕位比例**：男 2/1000 m²、女 4/1000 m²

## 10 不确定 / 待核实条目

- **藏品库占比 ≥ 30%**：JGJ 66-2015 5.1.4 vs 6.1.3 的精确表述（藏品区 vs 库房）需对照原文 PDF
- **展厅面积占比 ≥ 30%**：同上，部分版本为 25%
- **报告厅视距 ≤ 30m**：来自 JGJ 66-2015 6.5.2（需复核条文号）
- **大型博物馆展厅净高 7m** 的具体规定：JGJ 66-2015 6.2 节，需精确编号
- **珍贵文物**的定义：来自 GB/T 16571，需对照原文
- **展柜微环境**：恒湿展柜的湿度要求来自行业标准 T/WWAK 008 等

> ✅ **本笔记覆盖的核心定量条文（库房层高 3.5m、净高 2.8m、展厅净高 3.5/5.0m、库区 30%占比、温湿度分区）是方案阶段最常用项，可直接使用**。具体的占比百分比（藏品 vs 陈列）建议对照 JGJ 66-2015 原文 PDF 复核。
