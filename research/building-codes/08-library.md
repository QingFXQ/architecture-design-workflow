## 1 规模与功能构成

### 1.1 规模指标（任务书常见口径）

图书馆规模由三项共同定义，缺一项就无法校核：

| 指标 | 单位 | 说明 |
|---|---|---|
| 总建筑面积 | m² | 含地下，通常给 ±10% 弹性 |
| 总藏书量 | 册 | 决定书库面积与楼面荷载 |
| 总阅览座位数 | 座 | 决定阅览室面积 |

**三者必须自洽**，校核方法是反推，不是量图：

```
阅览室面积 ÷ 每座面积  = 阅览座位数        （3.0–4.5 m²/座，含开架参考书）
书库面积   × 藏书密度  = 藏书量            （开架 130–160，闭架 300，密集架 400–500 册/m²）
自习室面积 ÷ 2.0       = 自习座位数
```

`[经验]` 反推值落在行业区间内即为自洽；差 30% 以上说明功能表与面积表脱节。

### 1.2 功能构成（任务书典型 18 类）

门厅公共区 / 阅览室 / 外借处 / 教师研修室 / 学生自习室 / 报告厅 / 陈列厅 / 计算机房 / 馆长办公室 / 行政办公室 / 采编用房 / 修理工场 / 储藏间 / 设备用房 / 交通与卫生间 / 新书展销厅 / 藏书室 / 地下车库。

**易被漏掉的三项**：修理工场、储藏间、新书展销厅。任务书给了面积但方案常无处落位，需要在 Gate B 前显式处理。

## 2 防火与疏散

### 2.1 书库分隔（强制性条文）

| 要求 | 条号 | 标记 |
|---|---|---|
| 书库与其他部位之间应采用**防火墙**和**甲级防火门**分隔 | 6.2.1 | `[原文]` |

**墙与门是一对，缺一不可。** 只做防火墙不做甲级防火门，等于没做。

落地检查顺序：
1. 找出书库房间（闭架书库、藏书室、善本室、密集书库）
2. 取其围合墙 → 套防火墙类型（3.00 h）
3. **再核这圈墙上有没有门**，门的防火等级是否甲级
4. 核防火墙是否从楼地面基层隔断到梁板底面（GB 55037 6.1.1）

### 2.2 防火分区

| 建筑类别 | 分区上限 | 设自动灭火后 |
|---|---|---|
| 多层（≤24 m） | 2,500 m² | 5,000 m² |
| 高层（>24 m） | 1,500 m² | 3,000 m² |
| 地下 | 500 m² | 1,000 m² |

**必须逐层核，不要只算总量。** 差 1–2 m² 审查真的会挑。

> 实例：某方案 2F 楼板 2,501.33 m²，超多层限值 **1.33 m²**。这种数字必须显式处理（设自动灭火或拆分区），不能靠四舍五入过去。

### 2.3 24 m 高层线

GB 50016：建筑高度**大于 24 m 的非单层民用建筑**为高层。

一条 0.3 m 的差距能改整套措施：

| 项 | 多层 | 高层 |
|---|---|---|
| 防火分区 | 2,500 | 1,500 |
| 楼梯间 | 封闭楼梯间 | 封闭/防烟，条件更严 |
| 幕墙层间 | 常规 | 每层楼板外沿强制封堵 |
| 消防救援窗 | 不要求 | 每层每分区 ≥2 个 |

判定前必须确认三件事：**檐口高度是否含女儿墙、构架是否计入建筑高度、室外地坪起算点**。这三项各差 0.5 m 就能翻转结论。

### 2.4 报告厅

300 座级报告厅需：2 个安全出口、独立疏散楼梯、声光控制室、贵宾休息、储藏。疏散宽度按百人指标另核。视线与声学不属于规范强制，但属于设计质量。

## 3 采光与照明

### 3.1 窗地面积比

| 房间 | 采光等级 | 窗地比 | 标记 |
|---|---|---|---|
| 阅览室 | III | ≥ **1/5** | `[转引]` |
| 书库 | — | 以人工照明为主，避免直射阳光 | `[经验]` |
| 珍本/善本室 | — | 避光，防紫外线 | `[经验]` |

**按洞口面积算，不是玻璃面积。** 幕墙按透光部分折算。

核算流程：

```
1. 取房间净面积 A（不是建筑面积）
2. 需采光洞口面积 = A ÷ 5
3. 与立面现有洞口比对
4. 差额决定：加窗 / 改幕墙分格 / 调房间位置
```

> 实例：面湖阅览 214 m² → 需 43 m² 采光窗。若外墙零开洞，这不是“以后再说”——它直接决定开窗面积，进而决定立面。

### 3.2 书库照明

书架区垂直照度要求高于水平面照度；密集架通道需感应照明。珍本室避免紫外线，光源显色指数与照度上限另行控制。

## 4 隔声

### 4.1 允许噪声级（GB 50118-2010）

| 房间 | 允许噪声级 dB(A) | 标记 |
|---|---|---|
| 阅览室 | ≤ 40 | `[转引]` |
| 自习室 | ≤ 40 | `[转引]` |
| 报告厅 | ≤ 35 | `[转引]` |
| 办公/采编 | ≤ 45 | `[经验]` |

### 4.2 隔声核算

```
需要 Rw = 声源侧声压级 − 允许噪声级 − 安全余量(5 dB)
```

| 相邻关系 | 声源级 | 需要 Rw |
|---|---|---|
| 阅览室 ← 走廊 | 65–70 | ≥ 30 |
| 阅览室 ← 书库 | 50 左右 | ≥ 50 |
| 阅览室 ← 设备机房 | 80+ | ≥ 70（须结构隔振） |

### 4.3 200 mm 加气砌块的隔声边界

`[经验]` 单层 200 加气砌块（密度 600–700 kg/m³）Rw ≈ **45 dB**。

对比 4.2：对走廊够（需 30），**对书库不够**（需 50）。

三条改善路径，效果递增：

| 手段 | 增益 | 代价 |
|---|---|---|
| 加厚 | 质量每翻倍 +5~6 dB，效率低 | 占面积 |
| 双层墙 + 空腔 | +10~15 dB，最有效 | 厚度翻倍，需结构配合 |
| 独立龙骨、弹性连接 | 消除声桥，配合双层可达 +15 | 构造复杂 |

**结论：阅览室与书库之间的隔墙不能用单层 200 加气。**

## 5 墙体厚度：规范不给数字

> 国标里找不到“外墙 200 mm”这种句子。厚度是**四个约束取最大值**。

| 约束 | 输入 | 推导 |
|---|---|---|
| 防火耐火极限 | 构件角色：防火墙 3.00 h / 防火隔墙 2.00 h / 普通隔墙 1.00 h | 构造做法表 → 最小厚度 |
| 隔声 | 两侧允许噪声级 | 需要 Rw → 质量定律 → 厚度或双层 |
| 节能 | 气候区 + 建筑类别 → K 限值 | 有保温时厚度可减 |
| 结构 | 墙高、支承条件 | 高厚比 → 最小厚度 |

### 5.1 给出最小厚度的是各地砌块应用规程

`[经验]` 口径高度一致（各地文本略有差异）：

- 外墙 ≥ **200 mm**，强度 ≥ **A3.5**
- 户内隔墙 ≥ **100 mm**，强度 ≥ **A2.5**
- 潮湿房间隔墙 ≥ 100 mm 且做防水

**200 是下限，不是标准答案。**

### 5.2 200 加气砌块撞三条线

`[经验]` λ ≈ 0.16–0.20 W/(m·K)：

| 约束 | 200 加气的值 | 限值 | 结论 |
|---|---|---|---|
| 节能（夏热冬冷，乙类公建） | K ≈ 0.70–0.85 | ≤ 1.0 | 过 |
| 节能（同区，甲类公建） | 同上 | ≤ 0.80 | 卡边，必须加保温 |
| 隔声（阅览室 ← 书库） | Rw ≈ 45 | ≥ 50 | **不够** |

> 所以“200 够不够”的正确回答是：**对节能够，对甲类不够，对隔声不够**。
> 说“200 够了”或“200 不够”都是错的，必须说清对什么。

### 5.3 面积口径会反过来决定节能等级

物理总面积距某个整数分界只差几百平米时，**口径一动就翻等级**，代价是强制全年能耗模拟。

> 实例：物理总面积 19,631，任务书 20,000，距甲/乙类分界只差 369 m²。这种“差一点点”的状态必须在 Gate 前钉死口径。

## 6 无障碍（参照 GB 50763-2012）

| 项 | 要求 | 标记 |
|---|---|---|
| 室外坡道 | 坡度 ≤ 1:12，每段升高 ≤ 750 且设休息平台 | `[原文]` |
| 门净宽 | ≥ 800 mm | `[原文]` |
| 无障碍厕位 | 每层至少 1 个；每个无障碍厕所/厕位配呼叫按钮 | `[转引]` |
| 轮椅席位 | 报告厅按座位数 0.2%–0.5%，且 ≥ 1 个 | `[转引]` |
| 连续路径 | 室外场地 → 门厅 → 电梯 → 各层主要功能区，全程无高差 | `[原文]` |

**最易漏的是“连续路径”**：单看每一项都合规，串起来中间断一处就全部失效。必须画一条从入口到最远阅览座的连续路线核一遍。

## 7 武汉地方规定

| 项 | 要求 | 依据 | 标记 |
|---|---|---|---|
| 绿色建筑 | 政府投资的公益性公共建筑强制 **≥二星级** | 武汉市人民政府令第 310 号 | `[转引]` |
| 绿地率 | 文化、教育科研类项目 **≥35%**（JGJ 38 仅 30%） | 武汉市规划管理技术规定 | `[转引]` |
| 公共建筑节能 | 执行国标 GB 50189；湖北省 DB42/T 559 为**居住**建筑 | — | `[转引]` |
| 装配式比例 | 有要求，具体比例未取到现行文本 | — | `[待核]` |

### 7.1 高校图书馆正落在“强制二星级”里

这不是加分项，是**门槛**。二星级对围护结构热工、自然通风、可调节遮阳、雨水回用都有硬指标，**会反向影响立面开窗面积与幕墙构造**。

方案阶段就要知道，否则到施工图才发现外墙 K 值不够，只能加厚保温或改窗墙比。

### 7.2 一条已排除的

“大量人流集散建筑退道路红线 25 m”这条，图书馆类项目通常不适用——但需按项目实际与规划部门确认后写**字面结论**，不要在成果里留“待定”。

## 8 设计自查清单（图书馆专用）

- 书库围合墙是否防火墙**且**配甲级防火门
- 防火分区是否**逐层**核过，含 1–2 m² 级超限
- 建筑高度是否越过 24 m，越过后的四项高层措施是否到位
- 阅览室窗地比是否 ≥1/5，按洞口面积算
- 阅览室与走廊/书库/机房的隔声量是否分别核过
- 书库楼面荷载是否按常规架与密集架分列
- 藏书量、阅览座位数与面积三者是否互相自洽
- 借阅动线：门厅 → 出纳 → 开架书库 → 阅览，是否最短闭合
- 夜间独立使用区是否有独立交通核，闭馆后能否只开这一段
- 采编、卸货、书刊货梯与藏书室的垂直动线是否不穿公共区
- 恒温恒湿区是否避光、避外墙、避给排水管穿越
- 报告厅视线、声学、独立疏散、控制室
- 无障碍连续路径是否全程无高差
- 项目是否属强制绿建星级范围，窗墙比是否满足由此反推的热工要求
- 绿地率是否按 35%（而非 30%）复核
