# 04 日照间距与日照标准

> 本笔记涵盖方案阶段最常用的日照规范条文，包括住宅、学校、幼儿园日照标准，以及公共建筑间距常识。
> **注**：日照计算依据《城市居住区规划设计标准》GB 50180-2018 和《建筑日照标准》GB/T 50033-2024（住宅部分），学校、幼儿园执行各自专业规范。
> **警告**：日照分析属于方案阶段最常"翻车"的领域，规划部门审批卡控严，方案初期必须让建筑专业介入日照复核。

---

## 1 国家标准 GB/T 50033-2024《建筑日照标准》

| 项 | 内容 |
|---|---|
| 编号 | GB/T 50033-2024 |
| 名称 | 建筑日照标准 |
| 性质 | 推荐性国家标准（GB/T 编号即推荐性） |
| 实施日期 | 2024-08-01 |
| 来源 URL | https://www.mohurd.gov.cn/gongkai/zhengce/zhengcefilelib/202406/20240625_795443.html （公告） |

### 1.1 适用范围

- 住宅、医院病房、疗养院、老年人照料设施
- 中小学、幼儿园普通教室、活动室
- 集体宿舍

### 1.2 城市气候分区

按 GB 50180-2018 与 GB/T 50033-2024 的纬度分区：

| 气候区 | 代表城市 | 纬度范围（北纬） |
|---|---|---|
| **Ⅰ区（严寒）** | 哈尔滨、漠河、长春 | > 50° |
| **Ⅱ区（寒冷）** | 北京、天津、沈阳、大连、太原、济南、青岛 | 40°–50° |
| **Ⅲ区（夏热冬冷）** | 上海、南京、武汉、合肥、杭州、成都、重庆 | 30°–40° |
| **Ⅳ区（夏热冬暖）** | 广州、福州、海口、南宁、长沙 | < 30° |
| **Ⅴ区（温和）** | 昆明、贵阳 | 25°–30°（部分重叠） |

## 2 住宅日照标准（GB/T 50033-2024 第 3 章）

### 2.1 有效日照时间带

- **大寒日 8:00–16:00**（北方城市主流）
- **冬至日 9:00–15:00**（南方城市）

### 2.2 满窗日照时长

按气候分区最低要求（**硬性规定**，GB/T 50033-2024 表 3.0.1）：

| 气候区 | 有效日照时段 | 满窗日照时长下限 |
|---|---|---|
| Ⅰ区（严寒） | 大寒日 8:00–16:00 | **≥ 2.00h** |
| Ⅱ区（寒冷，北京、上海、苏州等） | 大寒日 8:00–16:00 | **≥ 2.00h** |
| Ⅲ区（夏热冬冷，武汉、南京） | 大寒日 8:00–16:00 | **≥ 1.50h**（部分地区冬至日 ≥ 1.00h） |
| Ⅳ区（夏热冬暖，广州、福州） | 冬至日 9:00–15:00 | **≥ 1.00h**（部分城市要求 ≥ 2.00h） |
| Ⅴ区（温和，昆明、贵阳） | 冬至日 9:00–15:00 | **≥ 1.00h** |

> 标记：**硬性规定**（GB/T 50033-2024 表 3.0.1，虽为 GB/T 推荐性，但被 GB 50180-2018 引用为强条）。

### 2.3 适用对象

- **每套住宅**应至少有 **1 个居住空间**（卧室或起居室）满窗日照达标
- 高层住宅塔楼（每户 4 居住空间）应至少有 **2 个居住空间**满足
- 老年人照料设施的卧室、起居室**全部**满足

### 2.4 满窗计算

- 计算起点：窗台面（外墙面起 0.90m 起算）
- 计算方法：**太阳轨迹 + 建筑遮挡** + 大寒日 / 冬至日 连续日照累计
- 阳台遮蔽：南向阳台进深 1.5m 内，阳台顶板遮挡部分可扣除计算，但内阳台不计

## 3 中小学日照标准（GB 50099-2011 4.1 节）

| 城市（气候区） | 日照标准 |
|---|---|
| Ⅰ区、Ⅱ区（北方城市） | 普通教室冬至日满窗日照 **≥ 2.00h** |
| Ⅲ区（夏热冬冷） | 普通教室冬至日满窗日照 **≥ 1.50h**（部分城市 ≥ 2.00h） |
| Ⅳ区（南方） | 不强制要求（但建议冬至日 ≥ 1.00h） |

> 来源：GB 50099-2011 4.1.3
> 标记：**硬性规定**。每栋教学楼 **≥ 2 间教室** 应满足满窗日照要求（4.1.4）。

### 3.1 普通教室朝向

- **南向**：最佳，南偏东 / 偏西 **≤ 30°**（详见 07-school.md）
- 东西向：避免东西晒
- 北向：仅辅助房间（卫生间、储藏）

## 4 幼儿园日照标准（JGJ 39-2016 4.1 节）

| 项 | 要求 |
|---|---|
| 活动室、寝室 | **冬至日满窗日照 ≥ 3.00h**（**最严**） |
| 满窗计算起点 | 窗台面（外墙面起 0.90m） |
| 活动室、寝室朝向 | 南向或南偏东 / 偏西 ≤ 30°（最佳），不得朝北 |
| 间距控制 | 幼儿园南侧建筑**不得遮挡**冬至日 9:00–15:00 满窗日照 |

> 来源：JGJ 39-2016 4.1.3
> 标记：**硬性规定**。幼儿园日照是方案阶段**最严**的，需专项复核。
> 详见 06-kindergarten.md。

### 4.1 间距快速估算（冬至日 3h 满窗）

按纬度估算幼儿园日照间距（简化速算）：

| 城市（纬度） | 冬至日 3h 日照间距估算（建筑高 H） |
|---|---|
| 北京（40°N） | **≥ 1.6H**（建筑南向） |
| 上海（31°N） | **≥ 1.4H** |
| 广州（23°N） | **≥ 1.0H** |
| 哈尔滨（46°N） | **≥ 1.9H** |

> 标记：**常见做法**（经验估算，正式方案需用软件复核：天正日照、众智日照、PKPM 阳光等）。

## 5 公共建筑日照与间距

### 5.1 公共建筑日照（无强条）

- 公共建筑（办公、商业、旅馆、博物馆、图书馆等）**无强制性日照时长要求**
- 设计目标：通过合理布局**争取**主要使用房间有自然采光
- 来源：《公共建筑节能设计标准》GB 50189-2015 引用 GB 50033 采光部分

### 5.2 公共建筑间距速查（经验值）

| 建筑类型 | 主朝向间距 | 备注 |
|---|---|---|
| 办公、旅馆 | **≥ 0.8–1.0H** | 满足消防 + 视觉卫生 |
| 商业综合体 | **≥ 0.5–0.7H** | 以消防为主 |
| 学校教学楼 | **≥ 1.4–1.9H** | 满足日照 |
| 幼儿园 | **≥ 1.0–1.9H** | 满足冬至 3h 日照 |
| 医院病房 | **≥ 1.2–1.6H** | 大寒日 2h |
| 老年人照料 | **≥ 1.5–1.8H** | 大寒日 2h 全房间 |

> 标记：**常见做法**（来自《建筑设计资料集》、各专业规范综合经验值，**非法定条文**，须按具体规范复核）。

### 5.3 防火间距（GB 50016-2014 表 3.4.1、5.2.2 等）

防火间距是**强制性间距**，与日照间距取**大值**：

| 建筑组合 | 一二级耐火等级 |
|---|---|
| 民用建筑之间 | **≥ 6m**（低层）/ **≥ 9m**（高层） |
| 民用与厂房 | **≥ 10–14m** |
| 民用与甲类厂房 | **≥ 25m** |
| 高层与高层 | **≥ 9–13m** |

> 标记：**硬性规定**。详见 01-gb55016-fire.md。

## 6 阴影遮挡与日照计算

### 6.1 计算软件（方案阶段常用）

- **天正日照**（T-Sun，天正系列）
- **众智日照**（PKPM 系列）
- **光辉城市**（可视化）
- **Grasshopper + Ladybug**（参数化）
- **IES VE / RhinoSolar**

### 6.2 计算要点

- **窗户宽度**：满窗计算按窗台面起，按**窗台面宽度**（不是房间开间）
- **窗户形式**：凸窗、转角窗按 GB/T 50033-2024 折算
- **遮挡物**：永久建筑（不考虑临时建筑）
- **地形**：山地坡度 ±0.5° 需修正
- **时区**：统一用**地方太阳时**（非北京时间）

### 6.3 典型问题

- **南低北高**：北侧高层遮挡南侧低层 → 北低南高方案
- **东西向建筑**：东西向布置减少遮挡，但需控制东西晒
- **退台建筑**：南向退台可改善后楼日照
- **点式高层 vs 板式**：板式对日照遮挡大，点式错落减少遮挡
- **女儿墙 / 屋顶构筑物**：超 1.5m 女儿墙计入遮挡高度

## 7 各城市地方日照标准（**重要：地方文件优先**）

> 各城市有**严于**国标的地方日照规定，方案前必须查询当地规划局文件。

| 城市 | 主要特点 | 查询路径 |
|---|---|---|
| 北京 | 严格执行 GB/T 50033 大寒日 2h | 北京市规划与自然资源委员会 |
| 上海 | 冬至日 1h（部分区域 2h）+ 大寒日 2h | 沪建交〔2014〕第 968 号《日照分析技术规程》 |
| 广州 | 冬至日 1h | 广州市规划局 |
| 深圳 | 冬至日 1h（部分 ≥ 2h） | 深圳市规划与国土资源委员会 |
| 杭州 | 大寒日 1.5h | 杭州市规划局 |
| 南京 | 大寒日 1.5h | 南京市规划局 |
| 武汉 | 大寒日 1.5h | 武汉市规划局 |
| 成都 | 大寒日 1.5h | 成都市规划局 |
| 西安 | 大寒日 2.0h | 西安市规划局 |

> 来源：各城市地方规划文件（住建部 / 规划局公告）
> 标记：**硬性规定**（地方文件批准后具有地方法规效力）。

### 7.1 上海日照分析特别要求（沪建交〔2014〕968 号）

- 分析范围：拟建建筑**遮挡区** + 受遮挡建筑**被遮挡区**
- 计算点：窗户左右各加 1/2 窗台高
- 有效时间带：冬至日 9:00–15:00 + 大寒日 8:00–16:00
- 满窗日照时长：每户**≥ 1 个房间** ≥ 1h（部分区域 2h）
- 受遮挡建筑：所有可能受影响的现状 + 在建 + 已批未建

## 8 老旧城区日照协调

### 8.1 改造项目特别提示

- 既有住宅日照**已不满足**现状，新建筑应**不恶化**其日照
- 部分城市（如北京、上海）允许**日照等时**换户（≥ 1 户达标的方案）
- 历史保护建筑：不受新建筑日照权侵犯（**绝对优先**）

### 8.2 城市设计控制

- 控规层面（详细规划）已明确**日照控制线**（建筑控制高度 + 后退距离）
- 方案阶段如突破控规，需**专题论证 + 公示 + 听证**

## 9 方案设计自查清单（日照）

1. ☐ 确认当地**气候区**（Ⅰ–Ⅴ）+ 适用日照标准（大寒/冬至 + 时长）
2. ☐ **每户**住宅**≥ 1 个**居住空间满窗日照达标（GB/T 50033-2024）
3. ☐ 老年人照料设施：卧室、起居室**全部**达标
4. ☐ 幼儿园活动室、寝室**冬至日 ≥ 3h**（最严！）
5. ☐ 中小学普通教室**冬至日 ≥ 2h**（北方）+ **≥ 2 间教室**达标
6. ☐ 南向布置优先，避免东西向主要房间
7. ☐ 间距按**日照间距**与**防火间距**取**大值**
8. ☐ 计算软件：天正 / 众智 / Ladybug 复核
9. ☐ 当地**地方文件**特殊要求（沪建交、京规土）
10. ☐ 改造项目**不恶化**既有建筑日照
11. ☐ 控规日照控制线核查
12. ☐ 高层塔楼遮挡分析（北低南高 + 错落 + 退台）

## 11 不确定 / 待核实条目

- **GB/T 50033-2024 表 3.0.1** 城市分区细化（按城市列出）需对照原文 PDF
- **日照计算软件** 的合法性：各地规划局认可的日照软件清单不同，需查当地规定
- **超高层（> 100m）** 对周边日照的影响评估：需做**专项日照影响评估报告**
- **山地建筑**（坡地）日照修正：来自 GB 50180-2018 第 5.3 节
- **玻璃幕墙反射光** 限制：GB 50352-2019 5.5.4，可见光反射比 ≤ 0.30

> ✅ **本笔记覆盖的核心定量条文（住宅大寒日 2h、幼儿园冬至日 3h、学校冬至日 2h）是方案阶段必查项，可直接使用**。具体城市的气候区归属与地方特殊要求须核对最新版 GB/T 50033-2024 + 当地规划文件。
