# Sheet 与图纸：图框、视图布置、比例及 CAD/PDF 导出

## 适用场景

- 适用于将 Revit 视图组织为课程提交图纸，并导出 PDF 或 DWG。
- Sheet 是发布容器；View 是模型/注释容器。二者分工清楚，修改才能稳定。
- 图纸品质主要由视图尺度、裁剪、图形层级和版式共同决定，而非最后拖拽位置。

## 核心决策

1. 先列图纸清单和每张图的叙事，再创建 Sheet。
2. 每张图纸使用正确尺寸的 Title Block；图框不是普通文字边框。[S1]
3. 视图比例服务纸面阅读距离，而不是只追求显示更多模型。
4. 同一视图不应为了不同图纸任意改比例；需要不同表达时复制视图并套对应模板。
5. PDF 是最终视觉核查物；DWG 是交换格式，需单独控制导出设置。

## 图框与标题栏

- Title Block 是可载入族，包含纸张边界、标题文字、参数标签和可能的修订信息。
- 用标准/课程规定图框优先；自制时从 Title Block 模板开始，不从项目绘制。[S1]
- 图框内项目名称、图号、日期、比例等应尽量由 Label/参数读取，避免每张手改。
- 一个作业通常只需一种主图框；不同纸张尺寸另建明确类型。
- 将 CAD 图框导入族时检查线宽、单位、文字和可打印范围，避免导出时比例错乱。[S1]

## 图纸清单与命名

- 先按叙事列：封面/总图、平面、立面、剖面、三维/分析、明细表。
- Sheet Number 使用稳定编号，如 A-001、A-101、A-201；Sheet Name 用简洁用途。
- View Name 描述内容，Sheet Name 描述发行版面；二者不要混成同一句。
- 图纸编号和视图标题应在建图早期确定，减少链接/引用后期失效。
- 用 Project Browser 组织图纸、视图和明细表，避免草稿视图被误上图。

## 视图布置方法

1. 先放主视图，确定纸面重心和最大阅读尺度。
2. 再放关联视图，如同层平面、剖面、立面或局部放大。
3. 将标题、比例、北箭/图例与视图建立清晰邻接关系。
4. 以统一留白和对齐线组织，而不是让每个视图填满空白。
5. 放置门窗表/面积表时留足列宽，避免压缩到无法阅读。
6. 最后放置不参与模型的文字说明、图例或渲染图。
7. 每放一张图纸就做 PDF 预览，早发现比例/裁剪问题。

## 比例的判断

- 总平通常需要较小比例，强调场地关系和北向；建筑平面/立面/剖面要能读门窗与空间。
- 同一张 Sheet 的相关平、立、剖宜使用可比较比例，例外时明确标在视图标题。
- 比例变小后，线宽和文字相对会显得更重；模板/线宽设置必须随比例验证。[S2]
- 不能以“Fit to Page”打印替代正确比例；这会破坏尺寸与线宽判断。[S2]
- 剖面/局部图需要更大比例时，使用 Callout 或独立视图，而非把全剖面硬放大。

## PDF 导出

- 导出前先确定纸张尺寸、方向、颜色/灰度、矢量/栅格和文件命名规则。
- 先导出一张代表平面和一张代表剖面，检查线宽、填充、透明度、阴影和文字。
- 再批量导出指定 Sheet 集；不要把工作视图或测试图纸混进集内。
- Revit 2026 版本提供后台 PDF 导出相关更新，但仍应以生成 PDF 实物验收。[S3]
- 最终检查应在 PDF 阅读器 100% 比例下进行，不只在 Revit 视口缩放看。

## DWG 导出

- DWG 导出前明确接收方需要 Sheet、View、图层映射、单位还是模型空间内容。
- Autodesk 的教程强调可在导出流程中选择显示的视图和图纸；先用小样本验证设置。[S4]
- 导出 CAD 图框/图纸时，检查是否需要保留标题栏、视口边界和注释。
- 每次课程交付如无明确 CAD 要求，PDF 是主成果，DWG 是附加交换件。
- 不要把 DWG 回导入 Revit 后当作唯一成果；这会失去 BIM 可编辑性。

## 优点

- 图纸清单先行可确保提交逻辑完整而不是堆图。
- 标题栏参数化降低图号、项目名和日期的手工错误。
- 视图与图纸分离，使同一模型可针对不同表达目的发布。
- PDF 预览把真正的纸面效果纳入质量控制。

## 风险与坑

- 在图纸上缩放/裁剪的误解常导致用户以为图纸改变了模型；应回到视图控制。
- 图框导入 CAD 时单位不一致，会产生极小/极大的纸面或线型问题。[S1]
- 一张图纸混用过多比例，读者会失去尺度比较。
- 导出前未清理测试 Sheet/视图，容易把不该交的内容批量输出。
- 屏幕上看似正常的线宽在目标纸张和 PDF 中可能过粗或过淡。[S2]

## 不适用情况

- 只需提交原生 RVT 的阶段不必花时间完成全部图纸编排，但应早设好视图模板。
- 需要印刷级排版、长篇图文或展板设计时，Revit Sheet 可出技术图，外部版式工具可能更适合最终合成。

## 课程作业建议

- 先建空 Sheet 和图号，再倒推每一类需要的视图；这会暴露漏项。
- 以一张最重要的平面图决定全套比例与线宽基准。
- 每天结束导出一张代表 PDF，避免最终才发现字体、线宽或透明度不对。
- 图纸标题少而有序：项目、图号、图名、比例、日期足够。
- 交付前在新文件夹批量输出 PDF，并逐页检查页数与图号。

## 图纸发布检查清单

- 确认图号没有重复。
- 确认 Sheet Name 与图号匹配。
- 确认图框尺寸符合提交要求。
- 确认项目名来自正确参数。
- 确认日期不是过期测试日期。
- 确认比例显示正确。
- 确认比例与实际视图一致。
- 确认北箭只在需要处出现。
- 确认主视图首先被阅读。
- 确认相关视图相邻放置。
- 确认留白均衡而非随机填满。
- 确认视图标题没有互相遮挡。
- 确认裁剪边界没有露在图纸上。
- 确认标注没有被裁剪掉。
- 确认表格有足够列宽。
- 确认图例有清楚标题。
- 确认每张图纸都有明确叙事。
- 确认平立剖比例便于比较。
- 确认局部详图比例被单独标明。
- 确认线宽已在 PDF 中检查。
- 确认灰度/彩色输出符合任务书。
- 确认透明度在 PDF 中仍可读。
- 确认文字没有变成替代字体。
- 确认字体大小在 100% PDF 可读。
- 确认输出集中没有草稿 Sheet。
- 确认输出集中没有重复版本。
- 确认 PDF 页数等于图纸清单。
- 确认 PDF 文件名有项目与版本。
- 确认 DWG 导出前已小样本测试。
- 确认 DWG 单位符合接收方要求。
- 确认 DWG 图层映射符合需要。
- 确认 CAD 图框没有比例错误。
- 确认最终 RVT 与 PDF 同版本。
- 确认保存了发布前备份。
- 确认提交文件夹没有无关文件。
- 确认每页标题栏完整可见。
- 确认每页图号和图名可读。
- 确认图纸不依赖屏幕缩放才能理解。
- 确认评阅者不用翻找就能找到主图。
- 确认最终输出在另一台阅读器可打开。
- 确认最后一次修改后重新导出 PDF。
- 确认发布工作优先于最后的装饰性修改。
- 确认图纸表达与模型数据没有冲突。
- 确认交付前逐页签核。
- 确认 Sheet 是发布容器而非临时画布。
- 确认输出结果而非 Revit 屏幕是验收对象。
- 确认每个版本可追溯。
- 确认交付版本已冻结。
- 确认所有必需成果都已在图纸清单中打勾。
