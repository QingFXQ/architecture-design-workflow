# 反馈闭环

当前主控记录、判断、改图和复验，不要求角色路由或Issue交接。用户要求先收集时，只记录并归纳，不提前改成果。

## 轻量处理

用一张短表记录：原话／被评版本／实际位置／处理动作／证据／剩余问题。教师原话、用户新要求、AI推断分开，不改写原意。截图不完整时自己查看完整原图／模型，不能只修截图内露出的部分。

先判断问题在哪一层：

| 层次 | 修在哪里 |
| --- | --- |
| 功能、空间、结构概念、流线、审美 | 可编辑工作模型及相关平剖，不靠涂色改标签 |
| 单位、宿主、约束、洞口、类别 | Revit／CAD实际对象，回读后看视图 |
| 剖切、投影、线型、字体、导出 | 正确的视图／图纸／排版控制层 |
| AI润色失真 | 回到真实底图重新生成，必要时先改设计模型 |
| 主次、图组、阅读与装饰 | 完整展板，而非零碎修补每个角落 |

用户已指定优先级就按其顺序；未指定时先修影响方案成立／必交图的问题，再修表现。普通可恢复修改按已有授权继续，不反复索取确认；重要冲突形成可见方案后集中沟通。

修改后看完整相关图面和受影响下游成果，不能以命令success或只修改标题结案。同版证据足够就结束，不为“规范”无限追求家具、数值或专项精度。
