# Project 持久文件模板

新 Project 只使用 Director、Concept Design、Scheme Design、Drawing Production、Visualization、Presentation 六角色。复制以下九个最小事实源，并建立追加式 `PROJECT_LOG.md`；任何阶段的详细工作均以对应 Skill、Issue 和主流程为准。

方案与画图按[共同检查约定](../../../../workflows/SCHEME_DRAWING_REVIEW.md)使用下列现有事实源；研究模型和正式生产分开，意图、数据、变更及证据不另建平行台账。项目专用尺寸、比例、语言和容量填在 BRIEF / DECISIONS，不写成通用技能默认值。

## `PROJECT.md`

```markdown
# PROJECT｜[项目名称]

## 当前状态
- 阶段 / 生效版本 / 最近 Gate：
- 当前核心问题（链接 `DESIGN_THESIS.md`）：
- 已确认 / 正在进行 / 阻塞 / 下一决策：
- 模式：Scheme 验证 / 正式 Drawing；技术准备度 / 用户批准范围分别记录：
- 工作流仓库位置／工程资产入口：填写本机当前路径；绘图按 `workflows/ENGINEERING_ASSET_WORKFLOW.md` 查相关资产，不全量读取资料。Revit／CAD路线按用户和任务选择。
- 当前工作模型：主体／立面／场地的依据文件、版本及待同步图件；Blender／SU可全程迭代。
- Gate B：深化中 / 技术资料可审核、待用户批准 / 已通过 / 变更后待重新审核：

## 版本记录
| 日期 | 版本 | 变化 | Director | 关联 Issue / 决策 |
|---|---|---|---|---|
```
