# 三维设计与可视化能力

先读[全程工作模型](../../../../workflows/CONTINUOUS_MODEL_WORKFLOW.md)。这是主控按需使用的能力，不要求独立Agent、Gate C后才能打开软件或先有RVT。

## 按当前任务做事

- 概念：识读CAD／PDF／图片并校准场地，做轻量可编辑体量、楼层与交通草案。
- 方案：结合平剖推敲功能、挑空、开放内梯、结构关系和室内外序列。
- 深化：可在授权范围内设计立面、屋面、支撑和室外地形，检查接地与相关图面。
- 表现：从当前真实模型取正投影、剖切、轴测及人视基底，再做基本材质／光影与可选AI润色。
- 反馈：模型与图纸持续更新，优先改善设计而不是重做精细灯光或家具统计。

Blender／SU按用户偏好和实际环境选择，不强迫双软件往返。已有工作模型优先复用，无需每阶段从Revit重新导入。

## 先核上下文

目标文件、授权修改范围、场地单位／坐标／标高、当前设计和所需输出。已有模型按对象语义与范围接手，不全清、不重复叠导。

跨软件分范围写明当前依据及待同步处；变更影响的平立剖及时更新。不固定RVT为唯一几何事实源，也不承诺自动BIM回传。

## 做完如何检查

关键设计修改看真实平面、剖面与三维；相机核建筑尺度、地面、遮挡和空间是否看得懂。对新相机先便宜预览，数量按问题和授权，不固定人工选镜头门槛。

截图／基础图与源模型、相机和用途对应。模型若有问题先修模型，不靠配景遮挡；用户已委托设计优化时可直接修，不要求一律退给另一个身份。

## 图像润色

只对某次明确快照应用[render-fidelity](../../../../skills/render-fidelity/SKILL.md)。润色保持该快照几何，设计阶段本身可以继续演变；修改几何后换基底重新出图。

输出可编辑BLEND／SKP（按实际使用）、必要预览／图件、简短当前版本与剩余边界。无本机工具时如实说明，不能拿AI图冒充已完成模型。
