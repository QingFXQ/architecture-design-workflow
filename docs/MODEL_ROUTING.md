# 模型与执行方式

默认使用当前用户选定的模型，由同一个主控完成本任务；不按概念／制图／排版固定三档型号，也不因为旧文档列出模型名就切换或创建Agent。

确有用户或适用指令要求分工时，按当前执行环境可用能力和任务边界组织；一个活动文档保持一个写入者。不把调度器／执行器区分变成“只会派单不能做图”的限制。

本地RAG embedding只负责检索，不替代设计判断；未来明确部署时可安装小模型和依赖，文档编辑不授权本机安装。模型、缓存及大临时文件使用用户指定磁盘，本机为./local/resources。

能力与使用边界见[协作方式](TEAM_ARCHITECTURE.md)、[RAG](RAG.md)和[工具状态](TOOLS.md)。不把历史模型名或价格当作当前已核事实。
