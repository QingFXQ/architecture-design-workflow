# 仅在确实需要时请求用户

不再把四个人工Gate、每个镜头或每项UI操作列为固定人工动作。已有授权范围内，当前Agent应完成可恢复设计、建模、制图、自检与收口，不把普通机械问题交给用户。

真正需要用户时：缺少决定方案的关键输入且无法从资料核实；改变明确冻结的重要设计且未被授权；账户／安装许可／插件交互只能由用户完成；真实模态或外部状态被阻断且当前工具无法安全处理。

先把可独立做的部分推进到具体可见，再集中说明位置、原因、已做工作与唯一必要动作。不能从旧机器、旧软件或旧安全限制推断“只有人能点”。操作成功后回读实际状态再续作，不重放历史写入。

代码、模型、图纸、相机和PDF检查应由执行者先做；用户审查是设计反馈，不是代替执行者排除显而易见的错误。
