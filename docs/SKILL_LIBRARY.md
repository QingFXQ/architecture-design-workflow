# 技能库按问题取用

保留原有技能与工程资料，入口短、细节按需读。不要一开始加载全部技能、让每个普通操作都经过整套体检。

| 实际任务／症状 | 入口 | 关键资料 |
| --- | --- | --- |
| 概念生图失真，想看可改方案 | concept-design | Blender／SU模型＋截图＋案例 |
| 功能、体块、开放内梯与场地 | scheme-development | 共同检查、全程工作模型 |
| Revit原生对象、宿主与构件方法 | revit-expert | references/engineering-manual，research/revit-materials |
| 找官方工程模板、门窗家具族、完整RVT样例 | RV-05、revit-expert | [原生数据库](../knowledge/engineering-assets/revit-library/README.md)，按版本／类别检索并复制工作文件 |
| 单位写错、Pending、模态超时 | revit-model-hardening | api-field-notes、运行恢复、小样 |
| 剖面像立面、地下对象串层 | revit-final-check、RV-03 | 有限剖切／真实Z范围、实际图面 |
| 非承重墙全黑、图内字体不对 | drawing-standard | graphic-hierarchy-revit、项目预设 |
| CAD图层／Block／墙断口／打印 | cad-production | CAD-01—04、参数化DXF样例、CAD工程经验 |
| 图像润色改了楼层或地形 | render-fidelity | 同版真实底图与几何对照 |
| 图纸机械拼图、字小、分析图空泛 | architectural-presentation | 排版案例库、真实爆炸模型、最终纸面 |
| 类型专项／合规问题 | building-code-check、museum-design、kindergarten-design | 按本项目适用部分与官方来源 |

技能具体位置在skills目录。原有大篇幅Revit工程方法与复核集合已拆到各技能references；概念／方案旧版和历史组织原文在docs/history，不作当前约束。

使用后按[维护流程](../workflows/SKILL_MAINTENANCE_WORKFLOW.md)回写根因、有效操作、样例和验证等级。没有宿主复验不能写host-verified；项目阈值、坐标和字体不提升为通用规定。
