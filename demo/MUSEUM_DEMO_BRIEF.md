# Museum Demo 任务书

## 项目背景
高校博物馆设计（建筑课程作业 Demo 项目，用于验证 Agent 团队工作流）。

- 建筑面积：约 8000㎡
- 场地：高校校园内，约 4m 高差（南高北低或东高西低，可假设由建筑师确定）
- 功能组成：
  - 常设展（校史/学科特色展）
  - 临展
  - 大厅（门厅/集散）
  - 报告厅
  - 办公
  - 后勤
  - 库房（藏品库）

## Demo 第一轮：Brief → Concept → Gate A → Scheme（模拟 Gate B）

目标：验证六角色团队能完成概念到方案的闭环，检查：

- Concept 是否堆资料而不是服务项目问题；
- Concept 是否给出 3–5 个可比较方向，而不是套话；
- Director 是否亲自包办，而不是拆解分派；
- 所有角色是否读取同一套项目事实源；
- Scheme 是否把选定方向落到总图、平剖、体量、面积与风险，而不是重复概念；
- 输出是否重复，Gate 是否被写成“已通过”。

## Demo 第二轮：教师反馈 → 反馈回环

输入：
«老师觉得现在入口太弱，参观流线也比较平，没有什么空间变化。»
用户想法：
«我想利用场地高差，让参观路线逐渐下沉。»

流程：Director 记录原话 → 判断影响阶段（Concept 或 Scheme）→ 对应角色修改 → 重新过受影响 Gate → 用户确认。

检查：教师原话是否被保留、AI 解释是否单列、方案问题是否回 Scheme、概念问题是否回 Gate A、修改是否同步平面/剖面/流线/面积、是否只给用户压缩结果。
