# 图书馆作业：真实反馈转成可复用方法

来源：本对话2026-10-25—29的用户反馈、WB-001—014交付摘录与仓库既有工程资料。性质：project-evidence／回顾整理；本轮没有重新打开原RVT／BLEND或复验每个历史数值。旧项目路径当前不可用，不把聊天摘要写成新的宿主验收。

## 设计组织

| 实际反馈／失败 | 原因与下一次做法 | 复核方式 |
| --- | --- | --- |
| 只用AI概念图，失真不可改 | 先在Blender／SU搭真实模型，截图后AI试氛围 | 模型可编辑，平剖轴测同版 |
| 地下两书库对角割裂，楼梯意义不明 | 按收书—采编—书库—货梯组织连续后勤，停车与坡道独立核 | 完整B1＋总平接地路线 |
| 主体被拉到湖边低地 | 建筑尺寸正确时先修场地，不随意迁建筑 | 原CAD、地形剖面与入口±0.000 |
| 两体量柱网乱穿 | 主体／斜翼分网并设计交界，按空间与支承优化 | 地下到屋面的结构关系示意 |
| 锐角、凹口缺理由 | 检查是否几何残留或不必要避让，成组理顺轮廓 | 平面转角＋外观，不只读尺寸 |
| 2F—4F内梯被塞进楼梯间 | 开放交通、沿外墙纵向挑空按空间设计，疏散核另核 | 连续三层平剖与人视 |
| 家具乱放，3F／4F／5F重叠 | 简洁成组，用真实复用桌椅；清穿墙／门／主要通路 | 全层原图＋三维，不限用户截图 |
| 盲追80万册／座席小数 | 先空间功能，按课程精度估算与抽样；目标／估算／实排分列 | 不把示意数量写成已核实 |

## 工程生产

| 实际失败 | 避免重犯的动作 | 入口 |
| --- | --- | --- |
| 米直接当英尺写墙 | 统一转换，先一件回读端点／高度／厚度，再批量 | RV-04、model-hardening |
| 看LevelId判无上层柱；看Stairs=0判没楼梯 | 查底顶约束、实体Z、DirectShape／梯段等真实表示 | RV-03 |
| 把首层墙投到地下、丢门洞 | 按真实B1剖切Z与墙实体取图，保留真实门／洞 | RV-03、制图流程 |
| 门实例生成但切不开墙 | 核族／宿主／标高，小样回滚并比较墙体积；临时门型如实标 | RV-02 |
| 楼梯平台标高／挤出方向／踏面数错 | 沿行进方向逐级核几何与洞口，用真实板厚，不只改文字 | RV-02 |
| 两Room同区、Pending被说成已提交 | 新建前核已有Room及边界，处理失败，Pending视为未完成 | RV-02／RV-04 |
| 警告弹窗卡住后不断排队 | Start后装失败处理，超时先查状态和真实模态，错误回滚 | RV-04 |
| 复制／重跑脚本覆盖旧包、重复建洞 | 输入输出路径、稳定ID／对象键和幂等更新，历史与当前分开 | CAD-04、工程样板 |
| 一律涂黑全部墙 | 区分承重／非承重、剖切／投影；普通墙玻璃门窗不黑填 | 图形层级参考 |
| 剖面像立面／一排柱挡住空间 | 换有空间信息的切线、缩合理深度，不全局改材质硬涂 | RV-03 |
| 立面双向拉伸标“1:200” | 真实正投影同一比例，核水平尺寸与楼层标高 | RV-03 |
| 图框内“通过”但地下车库没画 | 查真实内容完整性，不只测纸幅／墨迹范围 | 图纸复核 |

## 表现与出图

| 用户反馈 | 后续执行要点 |
| --- | --- |
| 立面简陋，先摆相机没有意义 | 先选择亮点并设计一个完整立面／空间样板，再镜头 |
| 灯光不必极细，后面AI渲染 | 基础材质与能看清的模型优先；机位构图细化，AI保持几何 |
| 参考不只是暖灰 | 提取天空蓝、水色、植被、木色与纸感等关系，不能缩减成单色标签 |
| 两张A1，喜欢竖版，机械拼图丑 | 看真实参考，定主图与阅读顺序，按最终毫米分配，再做分析图 |
| 图内字／图名小且生硬 | 以最终打印字高核全部字体，图内仿宋；展板标题另有层级 |
| 图名规范与标高符号 | xxx图＋比例，上细下粗双线；横向尺寸下置；标准标高符号 |
| 九千／一万八千漂在图名边不明 | 层高留在图内相应位置，不作为裸数随标题排布 |
| 花草程序感很重 | 如需植物装饰用合适生成／合法素材，顺构图少量放，不为填空滥贴 |
| 剖面全是横黑条 | 用真实空间剖切和真实切面厚度，远景轻，地下车库也完整 |
| 爆炸图一定要 | 独立三维副本真实分层展开，少量功能色／路径，不让AI造楼层 |
| 分析图数量要看剩余板面 | 先排版预案，再做爆炸／场地活动，体量推演有位再放 |
| 不要每步停等我审批 | 当前授权内主控自检继续，集中处理真正关键决定和实质阻断 |

这些是触发正确方法的索引，不是每次全量执行的检查表。通用工程方法见[制图流程](../../workflows/DRAWING_PRODUCTION_WORKFLOW.md)，项目特定字体／纸幅见[图形档案](wuchang-library.graphic-profile.json)。
