# 华南理工大学广州国际校区E3图书馆档案馆（E3 Library and Archives）

## 1. 初始条件

项目位于广州国际校区南北主轴南侧，正对校园仪式广场和主入口；隔滨河景观带与 E5 学生活动中心相望，东西邻公共教学楼和实验楼。

## 2. 核心设计问题

在知识传播方式转变、图书馆与档案馆合建、低碳与岭南气候适应要求之间建立空间原型。

## 3. 核心设计意图

“知识之冠、书山智谷”意在构建人、文化、空间与自然之间的安静联系。

## 4. 概念 → 体量

来源明确以覆土基座安置档案藏储，并将抬升主体组织为开放阅览空间；其余体量操作资料未提供。

## 5. 体量 → 总图

建筑面向校园主轴、仪式广场和滨河景观带布置，建立与 E5 的对望关系。

## 6. 总图 → 功能

覆土基座用于档案藏储，抬升主体用于开放阅览；具体房间与面积分配资料未提供。

## 7. 功能 → 平面

来源提供首层、二层和三层平面图；平面房间名称及精确流线不在此作推断。

## 8. 平面 → 剖面

来源提供剖面图；项目以气候适应性绿色校园建筑为目标，具体采光、通风构造资料未提供。

## 9. 平剖 → 立面与形体

设计强调空间、结构、建构逻辑、经济性和地域材料表达的一体化；具体立面材料参数资料未提供。

## 10. 人流与服务流线

读者、馆员、档案管理与后勤的分流资料未提供。

## 11. 尺度与模数

关键尺度和总建筑面积资料未提供。

## 12. 室内外关系

项目以滨河景观带为边界组织校园关系；室内外具体可达界面资料未提供。

## 13. 最值得学习的设计手法

- 先用功能安全性决定基座，再让开放阅览空间抬升。
- 以主轴、广场和滨河三重关系确定公共建筑位置。
- 同时用平面、剖面和概念图核对图书馆合建逻辑。

## 14. 可以迁移到其他项目的方法

适用于校园内图书馆、档案馆等安全等级不同的合建项目；需按档案恒温恒湿、防灾和本地气候重新分区。

## 15. 不应该机械照搬的内容

覆土档案基座及其校园主轴关系依赖本项目的档案需求和校园规划，不能抽离功能要求套用。
