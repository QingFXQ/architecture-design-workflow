# 凯州音乐山谷展览馆（Kaizhou Music Valley Exhibition Hall）

## 1. 初始条件

项目位于四川德阳凯州新城，属于凯州音乐山谷乡村文化产业园启动区示范段。展览馆项目名称为“人民渠水利文化中江纪念馆”，建筑面积2,800平方米；场地在公园西侧、东侧临水。

## 2. 核心设计问题

如何在新城和文化产业园中，以建筑保存人民渠从古代水利工程到现代灌区的技术成就，以及知青和当地群众共同建设的历史记忆。

## 3. 核心设计意图

设计将人民渠与凯州新城理解为跨越半世纪的时代对话，以展览馆连接水利遗产记忆与当代新城发展。

## 4. 概念 → 体量

来源以“建筑作为地形”为章节标题，表明建筑以地形化方式回应公园与水面；具体体量生成步骤资料未提供。

## 5. 体量 → 总图

建筑位于公园西侧、东临水面，是启动区示范段与发展引擎的一部分。精确出入口和道路关系资料未提供。

## 6. 总图 → 功能

展览馆承担人民渠水利文化的纪念与展示，并服务以音乐主题、音乐产业为核心的复合文化产业园。具体展陈、服务及后勤分区资料未提供。

## 13. 最值得学习的设计手法

- 将基础设施建设史作为新城公共建筑的核心叙事。
- 将展示节点嵌入产业园启动区，使文化记忆成为发展框架的一部分。
- 以地形化建筑回应公园与水面。

## 14. 可以迁移到其他项目的方法

适用于有工程遗产或集体记忆的新城展示建筑。策展内容与公园游线应同步策划，避免建筑成为孤立展亭。

## 15. 不应该机械照搬的内容

人民渠的水利记忆和音乐产业园定位均属地方条件；地形化形式须由真实水文、视线和游线决定。
