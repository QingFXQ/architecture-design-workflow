# Ponto C文化与创意中心（Ponto C – Cultura e Criatividade）

## 1. 初始条件

项目位于葡萄牙佩纳菲耶尔，面对 S. Martinho 广场和历史中心；于 2024 年完成。

## 2. 核心设计问题

如何借文化设施修复长期被称作“城市被一分为二”的断裂，并让大体量适应地形与现有建筑。

## 3. 核心设计意图

设计以新入口及向南侧区域的新连接，重置旧“背面”为面向广场的城市正面。

## 4. 概念 → 体量

体量隐入种植和玉兰树之间，保留旧建筑，并以喷涂软木的绿色外表皮与植被建立关系。

## 5. 体量 → 总图

接待广场引导访客入内；-1 层直接连花园、户外礼堂和通往 Cavalum 的步道。

## 6. 总图 → 功能

0 层为入口、门厅、售票和两处主要场所入口；-1 层设展览、咖啡厅和礼堂首层观众席；另设化妆间、安保和技术空间。

## 7. 功能 → 平面

来源提供总平和楼层平面图；具体房间尺寸资料未提供。

## 8. 平面 → 剖面

建筑共 -2、-1、0、1 四层；1 层为主舞台走台的技术层，具体剖面资料未提供。

## 9. 平剖 → 立面与形体

绿色喷涂软木随光线和观看角度变化；礼堂内部以深红色形成与外部的对比。

## 10. 人流与服务流线

-2 层技术层进行装卸，通过货梯服务所有楼层，避免与访客流线冲突；访客主要使用 -1 与 0 层。

## 11. 尺度与模数

四层（-2、-1、0、1）；其他关键尺度资料未提供。

## 12. 室内外关系

花园、户外礼堂及步道构成 -1 层的室外联系；种植和玉兰树缓和建筑体量。

## 13. 最值得学习的设计手法

- 将卸货与观众流线完全分层。
- 以广场—门厅—礼堂建立清晰抵达序列。
- 把景观连接作为城市修复的一部分。

## 14. 可以迁移到其他项目的方法

适用于历史中心边缘的展演文化中心；需评估高差、货运、声学和邻里噪声。

## 15. 不应该机械照搬的内容

绿色软木表皮和“背面变正面”的叙事依赖既有城市肌理，不能脱离场地关系复制。
