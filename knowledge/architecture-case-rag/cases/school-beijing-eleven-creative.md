# 北京十一学校学生创意中心（Student Creative Activity Center）

## 1. 初始条件

- **条件链：学生提出真实使用问题 → 旧校服中心进入校园改善清单 → 改造目标从修缮房间转为支持学生自治的创意场所。**
- 北京十一学校以学生主导、自由开放著称，每年由学生自主发起十项校园改善倡议，校方提供实施支持。
- 校区东北角原“校服中心”因空间体验差、功能使用频率低等学生关心的问题，进入 2023 年度“十事实办”清单。
- 项目位于教学区与生活区交汇处，理论上具备高频经过的区位，却长期因封闭和功能限制而人气不足。
- 既有建筑最初是地下混凝土鱼池，之后经历加盖与内部不断分隔，结构历史与功能历史并不一致。
- 地下层被用作书店和打印社，但阴暗、潮湿、通风不畅；首层校服储存展示区则拥挤闭塞。
- 这种室内状态与建筑周边宽厚松林、阳光和树影形成直接反差，未被利用的自然资源成为改造突破口。
- 用地面积为 570㎡、建筑面积为 830㎡，改造时间为 2023—2025 年，规模适合精细利用既有结构而非另建大体量。
- 项目由原地建筑完成建筑、室内和景观一体化设计，学生全程参与实施并在建成后自主策划内容。
- 既有建筑原始年代、各次加建年份、原结构图纸、地下防水状况及改造前准确面积分配资料未提供。

## 2. 核心设计问题

- **问题链：地下空间缺光缺风且首层封闭 → 使用率低；若只换功能不改剖面 → 新创意中心仍会继承旧空间缺陷。**
- 第一重问题是地下层的环境质量：原鱼池深埋、边界厚重，后来改成书店和打印社后仍阴暗潮湿、通风不畅。
- 第二重问题是上下层割裂：首层加盖与隔断没有把地面自然条件传给地下，两个楼层成为各自封闭的容器。
- 第三重问题是功能拥塞：校服储存、展示、书店和打印混杂，空间被固定用途占满，无法承接学生临时发起的活动。
- 第四重问题是既有结构负担：地下池壁承受挡土应力，首层楼板又要承担展厅荷载，开洞和拆墙不能脱离加固。
- 第五重问题是校园自然资源被隔绝：西侧松林近在咫尺，但原入口与外围墙体没有建立视线、停留和活动联系。
- 第六重问题是保留与更新的尺度：全部覆盖旧痕会丢失真实历史，全部保留又无法满足新的开放、荷载和环境要求。
- 第七重问题是活动不确定性：学生策展、阅读、交流、剧演和音乐表演需要可快速切换，而不是另一组固定专用教室。
- 因此核心设计问题被转化为“用结构性改造打通光、风、人和景观”，功能更新只是这一空间机制的使用结果。
- 防火分区、地下排烟、无障碍垂直交通、防水修复及既有结构检测的原始问题数据资料未提供。

## 3. 核心设计意图

- **意图链：承认旧鱼池的厚重历史 → 以其为“基石” → 在上部嫁接轻盈透明的“亭” → 新旧共同支持开放活动。**
- 设计没有把旧建筑视为应被抛弃或遮盖的缺陷，而把真实存在过的历史作为未来空间的基础。
- 地下鱼池保留粗粝混凝土与敲凿痕迹，使既有结构的年代、材料和不完美可以被阅读和触摸。
- 上部则以轻型金属构件、超白玻璃和折面屋顶形成林间廊亭，与地下厚重基座建立明确对照。
- “基石与亭”因此不是造型比喻，而对应承重方式、材料触感、采光条件和空间开放度四组差异。
- 设计围绕松林展开，把西侧改为主入口，让最有价值的自然界面成为校园到达的正面。
- 楼板开口、连续阶梯、地面狭缝与屋顶高窗共同形成纵向环境通道，把光、空气和树影导入地下。
- 清除隔断并释放两层连续空间，是为了容纳学生自主策展和不断变化的内容，而非预设单一活动。
- 林下竹木平台把室内活动延伸到树林、小木屋与校史树木周围，使创意中心成为校园网络节点。
- 完整意图可概括为“保留历史—结构加固—剖面打通—透明开放—学生运营”，任一环缺失都会削弱改造价值。

## 4. 概念 → 体量

- **生成链：保留地下池壁和旧框架 → 拆除隔断与外围实墙 → 首层透明化 → 抬起屋顶形成折面 → 轻亭落在厚基座上。**
- 地下体量基本沿用原鱼池边界，设计通过剥除装饰层而非重新包覆，让旧混凝土成为可见空间主体。
- 首层周圈外墙改为整块超白玻璃，封闭盒子由此转变为穿透视线的林间廊亭。
- 内部隔断被清除，原本碎片化的首层获得连续展陈和活动空间，体量从房间集合变成开放容器。
- 屋顶被“掀起”为连续折面，多个朝向的高窗在体量上制造抬升，使树梢、天空与热空气都有出口。
- T 型穿孔钢肋序列构成斜面骨架，同时为室内展陈预留隐蔽吊挂点，屋顶形态与运营需求合并。
- 正反双层直立锁边铝镁锰斜板整合屋面和吊顶，在减轻自重的同时组织雨水流向。
- 首层楼板被切开，通宽阶梯嵌入两层之间；体量不再由水平楼板完全分隔，而出现可见的竖向空腔。
- 西侧竹木平台从主入口悬浮伸出并绕树叠落，室外轻型构筑物延续“亭”的结构与空间气质。
- 既有框架截面、新钢构总重量、屋顶坡度、玻璃分格及拆除面积资料未提供，不能从概念反推。

## 5. 体量 → 总图

- **落位链：教学区与生活区交汇需要开放节点 → 选择西侧松林为主界面 → 入口与平台向林中伸展 → 北折连接闲置木屋。**
- 区位图显示项目是校园建筑群中的小体量节点，其价值来自连接周边教学、生活与树林，而非独占中心轴线。
- 西侧面对宽厚林带，改造将这一侧扩展为主入口，使日常经过人流先接触透明廊亭和林下平台。
- 竹木平台从入口向西延伸，围绕承载校史记忆的白皮松与碧桃层层叠落，树木被作为总图控制点保留。
- 平台随后向北转折，与林中闲置小木屋相接，把原本孤立的附属空间纳入新的活动网络。
- 首层通透后，建筑不再形成教学区与林带之间的视觉屏障，室内活动成为树林边缘可见的校园事件。
- 松下露台可容纳休息与自发音乐表演，室内活动通过平台扩散到林间，扩大 570㎡用地的实际使用范围。
- 建筑本体、平台、树木和小木屋共同形成“室内—檐下—露台—树林”的渐变，而非硬质入口广场。
- 总图改造没有新增独立地标体量，主要通过改变入口方向和外部连接来激活原有校园位置。
- 校园消防通道、设备运输、无障碍室外路径、树木根系保护范围和平台退界资料未提供。

## 6. 总图 → 功能

- **分区链：西侧树林适合开放活动 → 首层成为展览/交流廊亭 → 阶梯连接地下阅读与表演 → 储藏藏入阶梯后部支撑运营。**
- 首层释放出的连续空间作为学生自主策展的创意容器，透明边界让展览与校园日常互相可见。
- 地下封闭书店改为开放式环绕书架，阅读功能保留，但由独立商店转化为可共享的学习环境。
- 阶梯阅读区从地下延伸到地上，同时支持阳光阅读、分享交流和小型剧演，固定交通被转化为复合使用场所。
- 扩容后的校服储藏区隐藏在阶梯后部，避免储物占据开放界面，并可为剧演提供服装、道具和后台支持。
- 原打印相关空间仍见于地下层图纸，但改造后各房间的精确运营方式，来源未作完整文字说明。
- 重钢廊桥横跨阶梯上空，连接东西两侧首层空间，使展览流、林景流与上下层交流不因楼板开口中断。
- 松下露台承接音乐、停留和休息，把不需要室内条件的活动引向树林，减轻 830㎡室内的容量压力。
- 两层空间不再按“首层校服、地下书店”严格分割，而由策展、阅读、交流、剧演和储藏形成互相支撑的活动系统。
- 各功能面积、最大使用人数、打印社是否保留、卫生间及设备房改造范围资料未提供。

## 7. 功能 → 平面

- **平面链：不确定活动需要整块场地 → 拆除首层隔断 → 展陈沿连续空间展开 → 中部开洞与廊桥维持上下、东西两向联系。**
- 首层平面显示主要室内空间沿长向连续布置，西侧平台与松林形成主要外部扩展面。
- 清除隔断后，学生艺术展、交流活动和临时布置可以共享同一场地，不必受原校服库房房间边界限制。
- 地下层沿原鱼池的长条边界组织，开放书架靠周边设置，中央保留可变活动空间，适应阅读与小型剧演转换。
- 通宽连续阶梯沿墙下行，占据上下层最重要的连接位置，既是交通路径也是面向活动区的坐席。
- 地板狭缝沿楼板边界引入光和空气，平面中的“留空”成为地下环境设备而非损失面积。
- 扩容校服储藏隐藏在阶梯之后，前台活动与后台储物在平面上相邻，使临时表演可快速取用服装道具。
- 透空格栅重钢廊桥跨过开洞，恢复楼板被切开后东西两侧的水平联系，并将人流朝西侧松林强化。
- 外部平台围绕既有树木形成收放，平面边界服从树位和记忆节点，而非用规整矩形覆盖林地。
- 房间尺寸、开洞面积、书架容量、阶梯座位数、柱网与无障碍平面路线资料未提供。

## 8. 平面 → 剖面

- **剖面链：地下缺光缺风 → 切开首层楼板 → 阶梯和狭缝扩大上下联系 → 折屋顶高窗排热 → 光、风、人共用一条竖向通道。**
- 剖面清楚显示地下一层、首层和折面屋顶的叠合关系，楼板开口位于两层主要活动空间之间。
- 连续阶梯从地下上升至首层，使地下到达不再依赖封闭楼梯间，空间可达性与视觉联系同步改善。
- 楼板狭缝让阳光、新鲜空气和树影越过首层边缘进入地下，解决原书店最直接的阴暗与封闭问题。
- 屋顶连续高窗取景树梢与天空，并让室内热气向高处排出；低处开口与高处开窗形成竖向吐纳路径。
- 地下原鱼池壁继续承受侧向土压力，新植入钢梁在两侧墙体间对撑，加强旧墙的稳定性。
- 钢梁与压型钢板组合楼承板共同承担首层展厅荷载，开洞、加固与新功能荷载形成一套结构回应。
- 重钢廊桥跨越阶梯上空，剖面上把交通抬起，使下方阶梯保持通高和活动视线。
- 地下厚重混凝土与上部轻型金属折屋顶在剖面中清楚分层，“基石与亭”的概念由真实受力关系支撑。
- 地下防水节点、自然通风实测、排烟方式、结构验算值、层高及无障碍升降设施资料未提供。

## 9. 平剖 → 立面与形体

- **形体链：首层需要面向树林开放 → 周圈实墙替换为超白玻璃；剖面需要高位排热与取景 → 屋顶形成连续折面。**
- 立面透明度直接来自首层展览与交流空间对校园可见性的需求，而非独立的玻璃造型选择。
- 整块超白玻璃削弱反射与框架阻隔，使松林、学生活动和室内展陈在视觉上叠合。
- 折屋顶的高低变化来自高窗位置与排水方向，连续锯齿状轮廓把自然光分段引入长条空间。
- 轻型金属构件嫁接在保留旧框架上，新增形体避免继续增加地下池壁与原基础的负担。
- T 型穿孔钢肋既形成屋面斜面，也隐藏展陈吊点，室内顶棚不需再附加一套悬挂构架。
- 双层直立锁边铝镁锰斜板将屋面和吊顶整合，减轻自重并引导雨水，材料选择服从改造荷载和排水。
- 檐口拆解为封檐、雨水沟、导水槽、吐水口和垂链，雨水被收集、引导并返还地面，构造成为可见表达。
- 地下裸露、敲凿的混凝土与上部黑色钢构、玻璃和金属屋面形成新旧材料对照，旧痕不被伪装成新。
- 玻璃厚度、屋面热工、钢肋间距、雨水回用、檐口溢流和结露控制资料未提供。

## 10. 人流与服务流线

- **主流线：校园教学/生活区 → 西侧松林主入口 → 首层创意展陈 → 格栅桥横向穿越 → 连续阶梯下到阅读与剧演空间。**
- 西侧入口把人流直接导向最开放的林景界面，进入时即可辨认首层活动和地下阶梯的竖向联系。
- 重钢格栅桥连接东西两翼，并强化通向松林的景观方向，避免楼板开洞把首层切成两块孤岛。
- 连续阶梯同时承担下行、停留、阅读和观看表演，移动者与停留者共享界面但使用方式不同。
- 地下环绕书架释放中央活动区，读者可沿边缘停留，交流或剧演则占用相对开敞的核心。
- 校服储藏位于阶梯后部，演出服装和道具可以短距离抵达阶梯舞台，形成隐藏的后台支持链。
- 另一条室外流线从入口平台向西绕过白皮松与碧桃，再向北连接小木屋，把散步和偶发活动带入树林。
- 松下露台常转化为自发音乐表演舞台，室内外流线不以门为终点，而在林间形成可停留的环路。
- 学生自主策展和月度申请供不应求说明流动空间被高频使用，但具体峰值人数和管理分流资料未提供。
- 无障碍地下到达、消防疏散、货物搬运、校服补货和表演设备运输的独立路线资料未提供。

## 11. 尺度与模数

- **尺度链：570㎡紧凑用地 + 830㎡两层面积 → 不靠扩建获得容量 → 以开洞、阶梯、桥和林下平台提高单位面积复用率。**
- 用地面积为 570㎡、建筑面积为 830㎡，两者说明地下与地上空间的叠合是主要容量来源。
- 改造周期为 2023—2025 年，旧建筑经历地下鱼池、加盖分隔和创意中心三个使用阶段。

## 12. 室内外关系

- **关系链：松林原本只在墙外 → 玻璃让首层沉浸林景 → 高窗截取树梢天空 → 楼板缝把树影继续送到地下。**
- 首层透明界面使站立者与树林处于同一视觉层，建筑由封闭储存空间转为可穿透的林间廊亭。
- 高窗不是一般采光带，而是对准树梢和天空，使较高视域进入室内并参与热气排出。
- 地下使用者可从楼板狭缝和阶梯开口看到树影，原本完全内向的鱼池获得间接自然联系。
- 连续阶梯允许人坐下仰望树梢，身体姿态与视线高度共同改变室内外感知。
- 竹木平台在入口外绕树叠落，保护白皮松与碧桃的同时把树干、树荫和校史记忆纳入使用场景。
- 平台连接林中小木屋，使室外不只是观景背景，而成为创意中心可继续占用的学习与活动空间。
- 地下粗粝混凝土在狭缝光线中显露旧痕，外部自然光同时成为解释既有历史的展示媒介。
- 檐口以沟、槽、吐水口和垂链展示雨水返回地面的过程，自然联系从视觉扩展到可观察的水循环。
- 玻璃眩光、夏季遮阳、地下湿度、自然通风量、雨天平台防滑和树木建成后健康监测资料未提供。

## 13. 最值得学习的设计手法

- **首要方法：先做“问题剖面”而非功能平面，把缺光、缺风、挡土、楼板荷载和上下层割裂画在同一张图上。**
- 操作 1：区分必须保留的旧结构、可拆装饰层和需要加固的受力构件，保留应以真实性与性能为依据。
- 操作 2：开楼板前同时确定阶梯使用、地下采光、补风、排烟、桥梁跨越和新楼板荷载，避免单一目的开洞。
- 操作 3：用对撑钢梁加固承受土压力的旧池壁，再让组合楼承板承载首层展厅，使新结构一构多用。
- 操作 4：把交通放大成空间基础设施；连续阶梯既连接两层，又提供阅读坐席、交流看台和小型剧场。
- 操作 5：当开洞中断水平交通时，以透空桥恢复跨越，并利用桥的方向强化入口到核心景观的路径。
- 操作 6：将屋顶结构、自然排热、取景高窗、展陈吊点、轻量化和排水合并设计，减少各专业重复附加。
- 操作 7：把储藏紧贴可变活动空间并藏入阶梯后部，让后台支撑足够近、公众界面仍保持开放。
- 操作 8：以现有树位而非规则轴网生成室外平台，通过绕树、叠落和连接闲置建筑扩大校园资源网络。
- 学习重点是“一次剖面操作解决多种真实问题”，而不是复制玻璃亭、黑钢或锯齿屋顶的视觉语言。

## 14. 可以迁移到其他项目的方法

- **迁移框架：使用后评估 → 结构体检 → 环境剖面 → 复合开洞 → 可变功能 → 室外资源接驳 → 学生共治。**
- 适用条件 1：校园存在低使用率的地下/半地下小建筑，且周边有可转化为入口、平台或庭院的自然资源。
- 适用条件 2：既有挡土墙和框架经检测可保留，并允许通过钢构对撑、组合楼板及局部开洞完成加固。
- 第一步记录学生实际抱怨、时段客流与活动申请，确定问题是环境、可达、功能还是管理，而非先指定风格。
- 第二步用烟流、日照和温湿度分析选择低位进气、高位排热及采光开口位置，再与楼板结构共同校核。
- 第三步为每个新增构件设至少两项任务，例如“桥=水平连接+导向”“阶梯=竖向交通+活动坐席”。
- 第四步把固定储藏、设备和后台压到可变空间边缘，保留连续、少隔断、可吊挂的主要活动面。
- 第五步将树木、小屋、廊道等校园存量绘成资源图，用轻型可逆平台连接，减少新增室内面积。
- 第六步在运营前建立学生申请、策展、布撤展、安全巡查和内容更新机制，空间开放才不会止于建成照片。
- 若无法提供地下无障碍、排烟、防水与夏季遮阳，不应迁移整套空间；可先实施入口转向和室外平台等低风险部分。

## 15. 不应该机械照搬的内容

- **禁用链：先迷恋透明亭与折屋顶 → 忽略地下结构和校园运营 → 形式增加造价却不改善真实使用。**
- 大面积超白玻璃成立于松林景观与开放展陈需求；朝向、遮阳和防撞条件不同的校园不能直接环玻璃化。
- 折屋顶承担高窗排热、取景、吊挂和排水多项任务，若普通平屋顶已能满足性能，就没有复制轮廓的必要。
- 楼板开洞会改变受力、防火、排烟、声环境和无障碍组织，必须由结构与消防专项验证，不能作为“增加互动”的通用动作。
- 旧鱼池混凝土的粗粝痕迹具有项目历史真实性，异地人工做旧或敲凿新混凝土只会制造伪历史。
- 黑色钢构在本案中承担墙体对撑、楼板承托和桥梁跨越；没有受力理由时不应把外露黑钢当改造标配。
- 透空格栅桥有利于透光，但高跟鞋、细小物坠落、噪声和无障碍舒适性需按具体使用者复核。
- 林下竹木平台依赖白皮松、碧桃和闲置木屋的现场关系；必须先做根系保护、排水、防滑与耐久设计。
- 来源报告每月申请供不应求和持续活动，但未提供能耗、温湿度、噪声、拥挤或长期维护数据，不应把受欢迎等同于全面性能验证。
- 应迁移的是“学生问题驱动 + 新旧结构协作 + 多效剖面 + 共治运营”，不应照搬材料配色、屋顶姿态或林下意象。
