# Mercado in Groningen

## 1. 初始条件
项目位于荷兰格罗宁根市中心北侧，2023 年完成，属于商业、集合住宅的混合功能建筑。项目与 Rode Weeshuisstraat 更新和邻接的新 Stalplein 共同实施，包含 41 套可持续公寓。

## 2. 核心设计问题
如何以建筑和街道更新共同激活市中心北侧，并把城市转型导向步行与人际相遇。

## 3. 核心设计意图
设计团队将 Mercado 与 Rode Weeshuisstraat 的城市设计协同推进，使建筑及新 Stalplein 成为以行人与相遇为目标的城市更新组成部分。

## 4. 概念 → 体量
来源说明建筑由纪念性基座和其上的 41 套公寓构成；其他体量操作资料未提供。

## 13. 最值得学习的设计手法
- 将单体建筑与相邻街道、广场作为一个更新单元协同设计。
- 以强公共性的基座承托住宅，建立混合功能的城市界面。
- 将步行和相遇设为城市更新的明确绩效目标。

## 14. 可以迁移到其他项目的方法
适用于需要住宅、零售和公共空间协同的市中心更新。迁移时需明确基座沿街功能、公共空间管理和住户私密性边界。

## 15. 不应该机械照搬的内容
纪念性基座并非所有混合功能项目的通用解法；若没有足够的沿街活力和运营内容，可能反而削弱步行体验。
