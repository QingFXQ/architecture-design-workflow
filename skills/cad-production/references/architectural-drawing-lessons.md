# CAD工程绘图经验：从样板到纸面

方法级资料，未新增AutoCAD宿主验收。实例采用[参数化DXF样板](../../../knowledge/engineering-assets/examples/cad-parametric/README.md)，不能据此宣称DWG保存与AutoCAD发布已经通过。

- 接图先查UNITS／INSUNITS、已知尺寸、坐标／北向、Xref与字体，保留原文件；不能把比例因子乘两次或把研究范围当红线。
- 图层按墙／承重切面／柱梁／门窗／玻璃／轴线／尺寸／文字／家具／投影组织。可用项目命名，不把图层中文名当对象受力证明。
- 窗、门、桌椅用可复用Block；几何基点与插入点统一。批处理用稳定句柄或自有标识更新，不整图清空，也不重跑叠加几百个实例。
- 墙开门窗要有真实二维断口，不能只把窗块压在连续实墙上。剪切、图块和填充边界关系要实际查看。
- 文字用项目指定字体；核缺SHX、字体替换与中文导出。模型字高、注释性比例、视口缩放和纸空间字高分开理解。
- 比例标注与真实几何一致；不要靠DIMLFAC掩盖模型单位错。核总体尺寸和一个柱跨的实际读数，再看最终PDF。
- CTB／STB、线宽与填充在最终纸面测试；承重剖切填黑不等于全部墙体黑填，远景和玻璃保持轻线。
- 总平用真实场地底图；剖面选能说明空间的位置，地下、洞口和交通不能用平面自动投影或空白带假装完成。
- Layout按实际纸张与视口比例输出，避免Fit to paper二次缩放。PDF打开看整图及字／线局部，不能只检查文件字节数。
- DWG、DXF、PDF保存与回开分别验证。无AutoCAD时如实提供离线DXF与预览，不把扩展名改成DWG或宣称宿主测试通过。

新经验回到原样板／操作卡修正，注明版本、限制和验证证据；不把这张列表变成每次都重跑的全量审计。
