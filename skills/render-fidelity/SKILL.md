# 图像润色的建筑忠实性

本技能用于某次模型底图之后的图像润色，不将整个设计永久冻结。Blender／SU可按[全程工作模型](../../workflows/CONTINUOUS_MODEL_WORKFLOW.md)持续设计，不要求必须先有Revit或Gate C。

## 输入

当前设计快照、真实模型底图、相机／正投影／剖切方向、用途与尺寸，以及本次允许的表现变化。底图可来自Blender、SU、Revit或实际CAD图件；明确各自范围，不以生图凭空补工程关系。

采用用户已选择的设计／机位；在已委托选型范围内可自行比较优化，不追加一套固定相机审批。

## 可变与不可变

材质质感、光影、天空、人物、植被、水面和图底氛围可以按当前要求润色。保护体量、楼层、屋面、门窗、柱梁、入口、内梯、挑空、地形接地与透视关系；标注和尺寸优先独立准确叠加。

禁止用视觉美化掩盖几何错误。效果图若提出值得采用的新建筑做法，将其作为设计候选，在可编辑模型落实后换底图，不让图片悄悄替代实际设计。

## 检查与输出

- 对照原底图实际看轮廓、层数、开口、结构和关键空间，不以调用成功代替。
- 图像偏移先修生成结果；底图有错则返回工作模型修，更新相关平立剖。
- 超分后再看直线、细部与文字；保存原始基底、所用版本和当前结果，避免旧图继续充当新模型说明。
- 重要未知如实标明；不增加任务书以外的性能／结构结论，不为润色重做整套模型。

这个边界约束的是一次图片处理。用户授权的新设计迭代仍可继续，直到其接受并封版。
