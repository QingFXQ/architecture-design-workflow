# Revit图形层级：从对象语义到实际纸面

2026-10-28纠正：旧版“6/5/4/2适用于所有比例”“1:200不画家具”“一律改对象样式”等结论不再采用。这里只给方法；任务书与项目制图要求决定具体表达。

## 1. 先区分剖切、投影与辅助

- 被剖切的结构柱／梁／板等在项目要求时实心黑；未被剖切的梁或远处墙仍按投影表达。
- 非承重隔墙、幕墙、玻璃、门窗不因同属模型类别就统一填黑。先核结构身份与真实剖切，不把类型名当受力证明。
- 剖切轮廓、近远投影、家具／辅助信息应可辨；不为了凑“四档”把透明玻璃加粗。
- 图像／剖面背景不能凭二维粗线假装剖到了构件，先核剖切位置、方向与深度。

## 2. 找到控制结果的实际层

排查视图样板、类别／子类别、过滤器、单元素覆盖、线处理、族内可见性／符号线、细节级别及材质／剖切图案。类别不支持某种剖切覆盖或对象实际是投影时，改Cut参数不会产生预期效果。

对象样式影响全项目；视图模板可以合理统一表达，不能为了通过检查一律移除。需要视图级变化时优先处理相应模板／过滤器，确有全局错误再改对象样式或线宽表。

## 3. 线宽号不是纸面毫米

6/5/4/2只可作为过去某项目的试排起点，不是比例无关标准。当前线宽表、比例、打印缩放和输出方式共同决定纸面效果。不要把未经核查的默认表标为本机实测。

需要查线宽可用当前API的LineWeights相关方法或在界面读取；版本兼容先核。轴线采用项目需要的细点画线，不凭中文名称硬找任意“Center”图案。

## 4. 小样怎么验证

选一个同时有柱、非承重墙、玻璃、门、家具和轴线的典型平面，另取一个真正切到板／梁的剖面：

1. 核当前比例与实际输出纸幅；打开正常线宽显示，关闭影响判断的临时薄线模式。
2. 分别确认承重剖切填充、非承重围护与投影线、辅助信息，不仅回读数值。
3. 输出PDF，按实际纸面或100%比例观察，再看灰度是否可读。25%屏幕缩放只作辅助，不能替代打印尺寸检查。
4. 若最终板缩放，重新核字体及细线，不能沿用原比例的验收结论。
5. 小样成立后才推广到相关视图；不每次重复全模型对象样式盘点。

## 5. 家具与文字

家具是否显示按任务书；1:200常可能需要主要内部布置，不能一律隐藏。家具以可读、整齐、不严重重叠／嵌墙／堵路为主，不无故细分每种家具线宽。

需要区分家具时按可用参数过滤或族子类别处理，避免逐对象覆盖。标题、比例、标高符号与字体读项目预设；图书馆作业的仿宋／图名双线是课程要求，不冒充所有项目通用国标。
