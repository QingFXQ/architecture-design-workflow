# 建筑图纸、分析与展板

执行[表达交付流程](../../workflows/PRESENTATION_WORKFLOW.md)。先查[排版案例库](../../knowledge/presentation-cases/README.md)，看完整参考和局部；不拿整齐网格或“暖灰”标签代替视觉判断。

## 顺序

1. 核必交图、张数、纸幅方向、允许比例与已有图件的实际范围。
2. 用真实毫米建立构图预案，主图定调，其他图解释主体；先放必交图再决定分析图数量。
3. 分析图从真实模型制作，爆炸图分层切分并真实移动；功能、流线和通高与当前建筑一致。
4. 放入同版效果、图纸、分析、设计说明和有口径的指标；图内字体、图名、标高与尺寸按项目预设。
5. 输出PDF后自己看整版缩略图与100%局部，修主次、字、线、裁切和装饰；机械检查只作辅助。

## 重要限制

图纸内部名称与比例不能靠AI生成；结构切面与投影分开，剖面不能全是等粗黑条。最终缩放后重新核图内字高，不只是放大图名。

装饰服从参考和图面：可以生图制作植物／纸感素材，但不密铺、不侵入信息区，不用粗陋程序图案应付。整体色彩可以多样，保持文字和图线对比。

公开案例主要借用构图方法，注明作者与来源；未知许可不宣称免费PSD，不将别人图面当自己的成果。

本用户图书馆的两张竖A1、仿宋、图名双线等在[项目图形档案](../../knowledge/practice-feedback/wuchang-library.graphic-profile.json)。其他项目用其任务书；不得复制学生信息或虚构精确指标。
