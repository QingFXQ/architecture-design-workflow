# Museum Design 专业参照

## 使用原则

把本 Skill 当作“提问—推演—画图—复核”框架，不当作规范条文或固定答案。

1. 先回答关键问题，再建立功能、流线、剖面与环境控制模型。
2. 每个判断都写成“依据—设计操作—预期结果—验证图纸—风险”。
3. 同时画观众、藏品、布撤展、工作人员、设备维护、疏散与无障碍路径；不得用一张综合流线图代替。
4. 所有尺度和比例仅作为概念阶段起算值；依据所在地现行规范、任务书、藏品清单、运营数据及结构/机电/展陈顾问意见复核。
5. 信息不足时列出假设及其失效条件，不把参考值写成已确认事实。

## 协同位置与五段契约

本 Skill 是 Concept/Scheme 调用的博物馆类型专项检查，不是独立 Agent，不新增审批 Gate，也不替代 `building-code-check`。

### Required Input

- 当前任务、项目阶段、设计版本与已确认范围。
- 任务书、场地事实、规模、馆藏/展陈目标、运营方式和已确认用户意见。
- 当前概念包或方案图纸，以及需要本次检查回答的具体设计问题。
- 可用案例证据、适用规范清单与资料缺口；未知项必须显式标注。

### Required Output

- 与当前版本绑定的博物馆专项判断，按阶段交付：

| 调用阶段 | 必须交付 | 不应提前要求 |
| --- | --- | --- |
| Concept | 关键问题、假设、类型风险、方向级流线/面积/剖面意图与适用 checklist 项 | 展项完整试排、精确尺度图、运输/日照模拟或 1:20/1:50 图 |
| Scheme | 面积与邻接、观众/藏品/员工/疏散流线、展陈试排、关键剖面、光环境与运营风险 | — |
- `MUSEUM_CHECKLIST` 结果，每个未通过项写明证据、影响、责任人、补证方式和复核节点。
- 区分项目事实、方案起算值、专业建议和必须查原规范/顾问确认的事项。
- 对当前 Concept 或 Scheme 成果的最小修改建议，不直接改写用户已批准的核心概念。

### Exit Criteria

- 本轮专项问题均有图纸或明确资料证据，不用类型常识补造项目事实。
- 观众、藏品后勤、运营维护与疏散/无障碍至少完成一次交叉检查。
- 面积、展陈、运输、结构机电与光环境的阻塞风险已指出归属和复核方式。
- 输出能被调用本 Skill 的责任 Agent 直接写回当前概念包或方案确认包。

### Return Conditions

- 缺任务书、场地、馆藏/展陈或运营关键事实时，返回 Director 请求最小补充资料。
- 当前方案违反已通过 已确认概念 的核心原则时，返回 当前主控；不得以类型优化名义偷偷改概念。
- 专项检查暴露总图、功能、平剖或流线问题时，返回 当前主控 修正。
- 规范版本、项目地或关键数值不确定时，调用 `building-code-check` 并保持“待专业确认”，不得宣布合规。

### Next

- 概念阶段完成后，Next 为当前 当前主控 汇入 已确认概念 概念比较包。
- 方案阶段完成后，Next 为当前 当前主控 汇入 当前方案基准 方案确认包。
- 未通过项按 Return Conditions 精确返回；本 Skill 不直接交给 Drawing Production Agent。

## 1. 设计前必须回答的问题

在提出体量前回答以下问题；无法回答的项进入 `待确认事项`。

1. 博物馆的首要使命是什么：校史传播、学科收藏、公共文化、教学研究，还是复合运营？什么使用结果能证明使命成立？
2. 核心观众是谁，年客流、设计日客流、瞬时峰值、团体比例、停留时长和无障碍需求分别是多少？
3. 常设展、临展、特展和教育展各占多大规模，更新频率、闭展周期与独立开放需求是什么？
4. 展览叙事采用时间线、主题并列、核心藏品驱动还是混合结构？章节、转折、高潮与收束如何落到空间？
5. 单线、多线、自由流线中哪一种适合内容与人群？是否需要短线、跳读、逆向参观、提前退出和重复进入？
6. 展陈密度如何定义：单位展墙/面积的展项量、阅读量、观看距离、停留时长与人群容量是否匹配？
7. 最大、最重、最脆弱和最敏感展品分别是什么？含包装后的尺寸、重量、转弯半径、吊装和环境要求是什么？
8. 藏品是否经历接收、隔离、拆包、摄影、修复、暂存、入库与出展？哪些环节必须在馆内完成？
9. 临展能否在常设展开放时独立布展、撤展、封闭、收费和夜间运营？
10. 大厅、报告厅、教室、文创、咖啡等公共设施能否在闭馆时独立开放？权限边界在哪里？
11. 入口是否售票，安检、预约、晨间团体、贵宾、存包、导览与离馆回收如何组织？
12. 哪些展厅必须无柱、大净高、重载、吊挂或完全遮光？哪些空间允许结构和自然光成为展览的一部分？
13. 各类展品的照度、累计曝光、温湿度波动、空气洁净度与振动限制是什么？
14. 4m 高差如何服务主入口、后勤入口、双首层、无障碍到达、消防与城市公共空间，而不是只制造台阶？
15. 沿街/校园界面在开馆、闭馆和活动日三种状态下分别如何使用？标志性是否牺牲展厅、库房或运营性能？

## 2. 功能与面积框架

### 2.1 8000㎡级起算模型

以下按总建筑面积约 8000㎡建立第一轮配比；随后用藏品流程、峰值客流和运营岗位逐项反推。

| 板块 | 起算比例 | 8000㎡示例 | 为什么 | 检查什么 | 常见错误 |
|---|---:|---:|---|---|---|
| 展陈 | 32%–38% | 约 2800㎡（35%） | 体现核心使命，也要给临展留弹性 | 常设/临展/序厅面积、展墙长度、展陈密度、闭展影响 | 只按房间面积，不核可用展墙和观众容量 |
| 公共服务与教育 | 15%–20% | 约 1440㎡（18%） | 峰值集散、教育和独立运营决定真实需求 | 门厅、安检、存包、休息、卫生间、教室、报告厅、文创 | 用巨大中庭替代服务空间 |
| 藏品与展览后勤 | 12%–17% | 约 1200㎡（15%） | 藏品安全依赖完整处理链而非一个库房 | 卸货、隔离、拆包、暂存、修复、库房、布展制作 | 只留货梯和库房，撤展无暂存 |
| 办公与研究 | 7%–10% | 约 640㎡（8%） | 策展、研究、行政和员工运行需独立权限 | 岗位数、会议、档案、研究接待、员工更衣休息 | 办公与公众/藏品路径互相穿越 |
| 交通、设备、卫生间、墙体 | 20%–25% | 约 1920㎡（24%） | 大跨、恒温恒湿和分流会提高支持面积 | 各类交通效率、机房竖井、设备夹层、墙体结构 | 净面积相加后才被动压缩设备与交通 |

不要强求范围中值相加恰为 100%；先选定一个总和为 100% 的项目版本，再记录调整理由。

### 2.2 展览体系推演

| 决策 | 为什么 | 检查什么 | 常见错误 |
|---|---|---|---|
| 常设展与临展关系 | 更新周期、观众复访和布撤展扰动不同 | 是否可独立到达、封闭、收费、运输和使用公共服务 | 共用唯一前厅或唯一货运口，换展迫使全馆闭馆 |
| 叙事结构 | 空间次序必须服务内容理解 | 为每章标出入口预告、核心展项、转场、休息和退出 | 把展厅串联等同于叙事，章节没有强弱与转折 |
| 展陈密度 | 信息过密会降低停留质量并造成拥堵 | 用展墙长度、展柜数量、阅读字量、观看距离、停留时间和峰值容量联合试排 | 用“丰富”掩盖堆展项，或大面积留白却没有叙事作用 |
| 展陈模数 | 临展变化要求空间与接口同步可变 | 展墙模数、吊点、灯轨、电源、数据、地插和展柜是否协同 | 只有可移动隔墙，机电和消防位置完全固定 |

每个展厅至少输出一张 `展项—观看距离—驻足区—通过区—容量` 试排图；面积表不能替代试排。

## 3. 流线组织原则

### 3.1 观众与公共空间

| 要点 | 为什么 | 检查什么 | 常见错误 |
|---|---|---|---|
| 到达与入口集散 | 高峰排队发生在安检前，不应回堵校园道路 | 广场排队、团体集合、雨棚、应急集结、安检前后容量 | 入口形象突出但前场无等候余量 |
| 首次决策点 | 观众进入后需迅速理解去向 | 售票、咨询、安检、存包、卫生间、常设/临展入口是否可见 | 服务台藏在转角，逆行寻找存包 |
| 单线参观 | 适合连续叙事且易控流 | 总长度、参观时长、中途退出、回到大厅和疏散替代路径 | 强迫看完全程，疲劳后只能逆行 |
| 多线参观 | 适合主题并列与复访 | 分叉前是否预告内容与时长，汇合点是否拥堵 | 路径选择很多但无清晰层级 |
| 自由流线 | 支持自主探索 | 视线锚点、回环、边界、方向确认和重复参观 | 把“自由”理解为没有导向 |
| 可逆与短线 | 应对时间差异、闭展和高峰调度 | 反向门控、跳过章节、提前退出是否不穿越后勤 | 图面可逆，实际被闸机、窄门或单向扶梯锁死 |
| 节点与休息 | 控制观展节奏和疲劳 | 在章节转场、竖向转换、长线中段设置可坐、可辨向、不阻流的节点 | 座椅放在展项前或疏散口形成堵点 |
| 大厅/中庭/交通 | 公共空间应承担集散、辨向和活动任务 | 峰值容量、视线、声学、排烟、能耗、闭馆边界 | 以巨大中庭制造“气势”，实际方向混乱且耗能 |
| 观众服务 | 服务设施影响完整体验 | 饮水、卫生间、母婴、无障碍、急救、文创、咖啡的时点与权限 | 服务集中在入口，长线中途没有支持 |
| 疏散 | 展陈变化不能削弱生命安全 | 疏散宽度、距离、出口可见性是否独立于叙事和可变展墙 | 把参观主线当唯一疏散线 |

主体验流线必须在平面与剖面同时表达：标出宽度、净高、坡度、明暗、视线、停留时间和人流冲突。

### 3.2 藏品、布撤展、维护与办公

| 流线 | 为什么 | 检查什么 | 常见错误 |
|---|---|---|---|
| 藏品运输 | 安全取决于从车辆到展位的连续链条 | 车型、封闭卸货、月台、门洞、货梯、坡度、转弯、地面荷载、吊装点 | 只画货梯，最大包装箱进不了门或转不过弯 |
| 接收与暂存 | 展品不能从室外直接进入展厅 | 安检/隔离、拆包、状况检查、摄影、暂存、空箱存放 | 将走廊当拆包与暂存区 |
| 布展撤展 | 临展切换常与常设展运营并行 | 临展到货梯距离、夜间权限、制作区、垃圾与包装物路径 | 撤展物料与开放观众交叉 |
| 维护 | 灯具、风口和设备需要常态检修 | 展墙背后、吊顶马道/检修口、设备通道是否可独立到达 | 每次维护都要闭展、移柜或进入库房 |
| 清洁与补给 | 气味、垃圾和推车会干扰展览 | 清洁间、垃圾、餐饮补货、污洁分流与服务电梯 | 咖啡补货穿越大厅或藏品通道 |
| 办公与研究 | 权限与工作效率需要兼顾 | 独立员工入口，办公到展厅/库房的受控联系，访客研究接待 | 员工需经过检票，外来研究者直接接触核心库区 |

硬约束：藏品主运输线不得穿越观众大厅、公共走廊和客梯厅；确需时段共享的局部必须明确物理隔离、时间窗口和运营责任，不能仅标“错峰”。

## 4. 空间与尺度要点

数值为方案起算区间，不是规范替代。

| 对象 | 推演起点 | 为什么 | 检查什么 | 常见错误 |
|---|---|---|---|---|
| 常设展厅净高 | 约 4.5–6m | 适配多数展墙、展柜和灯光层 | 最大展项、观看距离、吊顶设备叠合后的净高 | 只标层高，不标完成面净高 |
| 大型临展/装置展净高 | 约 6–8m，按展项复核 | 支持吊挂、大型装置与更新 | 吊点、检修、运输门、结构高度和安装工法 | 空间很高但展品进不来、吊点不可达 |
| 柱网与跨度 | 可从 8.4–12m 级模数或局部无柱比较 | 展墙连续性与灵活性依赖结构 | 柱位、展墙模数、风口、灯轨、展柜和运输线 | 柱子后期包入假墙，损失面积且方向混乱 |
| 展墙 | 用内容试排确定长度与模数 | 展厅面积不等于可展面积 | 连续长度、转角、门洞、吊挂、背后检修、消防影响 | 门和设备口切碎主展墙 |
| 楼地面 | 均布荷载可从 5–7.5kN/㎡级预判，重载专项核定 | 展柜、密集人群和大型展品荷载差异大 | 集中荷载、振动、平整度、低反光、耐磨、缝位、可修复 | 普通楼面假设覆盖所有展厅和库房 |
| 入口门厅 | 由峰值到达和处理能力反推 | 安检、团体和存包决定有效面积 | 人群排队模型、闸机吞吐、安检前后分区和回流 | 用日均客流估算峰值空间 |
| 货运空间 | 由最大包装件反推 | 最窄处决定运输能否成立 | 门净宽高、转弯包络、货梯轿厢、月台、坡度 | 只核展品裸尺寸，忽略包装与搬运设备 |

### 展陈灵活性最小组合

- 可拆装展墙与统一定位模数。
- 可调灯轨、分区控制和可扩展回路。
- 均匀或预留的吊挂点、供电、数据及地面接口。
- 可调整风口策略与消防复核边界。
- 独立的布展暂存、制作和包装物存放。

只有隔墙可移动不算“灵活展厅”；改变布局后仍要复核疏散、喷淋、探测、照明、风量和无障碍通行。

## 5. 光环境策略

| 策略 | 为什么 | 检查什么 | 常见错误 |
|---|---|---|---|
| 先按光敏感性分区 | 不同藏品可承受的光剂量差异极大 | 纸本、纺织、照片等高敏感展品与低敏感展品是否分区 | 按展厅朝向分光，不按藏品分光 |
| 照度与累计曝光并控 | 瞬时合格不代表长期安全 | 高敏感展品可从约 50lx、普通展品从约 150lx 级试算，并核年度光剂量、UV及轮换周期 | 只看照度表，不记录展示时长 |
| 天光可调、可关 | 天气与展览变化要求完全控制 | 漫射、遮阳、遮光、排水、清洁、检修和失效状态 | 造型天窗无法完全遮光，漏水后难维护 |
| 侧光防直射与反射 | 展柜玻璃和亮面展品易眩光 | 太阳路径、观众视角、玻璃反射、窗帘盒和边缘漏光 | 只算采光量，不做视点反射检查 |
| 人工光可变 | 临展更新需要快速重设焦点 | 显色性、光谱、眩光、垂直照度、轨道与回路模数 | 固定筒灯阵列与可变展墙不对位 |
| 明暗适应 | 亮度骤变影响观看与安全 | 高亮大厅到低照展厅之间是否有过渡区 | 展厅入口正对玻璃幕墙 |

优先把可控自然光用于大厅、交通、休息和章节转场；自然光进入展厅必须有明确的展品适配、控制系统和完全关闭方案。

## 6. 结构与设备要点

### 6.1 大跨与结构

| 选项/问题 | 为什么 | 检查什么 | 常见错误 |
|---|---|---|---|
| 钢梁/钢桁架 | 适合较大跨度和快速建造，但结构高度、耐火与振动需控制 | 跨度、桁架层设备穿越、挠度、耐火、防腐、吊点 | 桁架与风管争夺同一高度 |
| 预应力混凝土 | 刚度、耐火和整体性有利，但自重与施工条件影响方案 | 跨度、梁高、预应力路径、开洞、工期 | 后期开洞破坏受力逻辑 |
| 钢—混组合/局部转换 | 可协调不同柱网，但转换区代价高 | 展厅与下层柱网关系、结构高度、振动和造价 | 为造型大量转换，设备无处通过 |
| 局部大跨而非全馆大跨 | 把资源用于真正需要灵活的展厅 | 哪些空间必须无柱，哪些可用常规柱网 | 把所有空间都做大跨，成本高且层高失控 |

不替结构专业计算，但必须在关键剖面表达柱网、受力方向、稳定体系、大跨构件高度、吊挂荷载与运输集中荷载。

### 6.2 层高与设备

用以下叠合反推建筑层高：

`完成面净高 + 灯光/吊挂层 + 风管/水管/桥架/消防层 + 结构高度 + 安装检修余量`

| 系统 | 为什么 | 检查什么 | 常见错误 |
|---|---|---|---|
| 空调与恒温恒湿 | 展厅、库房、修复和公共空间稳定性不同 | 独立分区、缓冲间、气密、风速、风口不直吹、故障响应 | 全馆共一控制逻辑，门厅波动传入展厅 |
| 消防 | 展墙变化和大空间会改变覆盖条件 | 喷淋、探测、排烟、疏散标识与吊点灯轨叠合 | 布展后遮挡喷淋或出口标识 |
| 机房竖井 | 短路径和可维护性影响净高与运营 | 风管断面、竖井位置、设备更换路线、独立检修 | 机房够大但设备无法更换 |
| 声学与振动 | 报告厅、设备和人群会干扰观展及藏品 | 机房隔振、展厅背景噪声、报告厅邻接、楼板振动 | 把报告厅或冷机房贴临安静展厅 |
| 安防与权限 | 藏品安全依赖空间边界和系统协同 | 门禁、监控盲区、安检层级、库区缓冲、闭馆分区 | 用摄像头补救失控的流线交叉 |

## 7. 场地与城市公共关系

### 7.1 从城市到展品的空间序列

按以下节点推演并在总图、平面、剖面连续验证：

`城市/校园路径 → 可识别前场 → 遮蔽与排队 → 门槛 → 安检/服务 → 总体预告 → 叙事起点 → 展览转场 → 核心展项 → 休息/回望 → 离馆与公共活动`

对每个节点记录尺度、明暗、开合、视线、声环境、停留时长和行为；“庄重、震撼、流动”等形容词必须翻译为空间操作。

### 7.2 4m 高差原型比较

| 原型 | 机会 | 必查项 | 常见错误 |
|---|---|---|---|
| 台地型 | 高侧接校园主入口，低侧容纳后勤/设备 | 主次标高、挡土排水、无障碍连续、消防到达 | 形成大量挡墙，室内仍是普通叠层 |
| 双首层型 | 公共设施可分时开放，连接不同城市界面 | 两入口等级、票务边界、室内辨向、疏散口计入方式 | 两个入口互相削弱，观众不知道从哪里开始 |
| 半下沉型 | 利用高差隐藏后勤并形成屋面公共平台 | 防水、防洪、冷凝、采光、设备维护和应急转移 | 把高价值库房放在高风险挡土侧 |
| 连续坡道/缓降型 | 把地形转化为参观节奏 | 坡度、长度、休息、展陈可用性、无障碍与疏散 | 为“下沉体验”制造过长路径和单一节奏 |

### 7.3 沿街界面、广场与标志性

- **为什么：** 博物馆既是受控文化设施，也是校园/城市公共节点。
- **检查什么：** 沿街首层开放度、闭馆后可用路径、广场日常活动、夜间边界、入口可见性、建筑与周边尺度；分别模拟普通日、开幕日和闭馆时段。
- **常见错误：** 广场只适合仪式照片；透明大厅导致展厅眩光与能耗；用异形外壳制造标志性，却牺牲展墙、结构和维护。

标志性优先来自“到达—入口—公共空间—地形”的清晰关系，而不是附加造型。

## 8. 常见设计错误（反面清单）

| 错误 | 为什么会失败 | 纠偏测试 |
|---|---|---|
| 先做标志性体量，再塞功能 | 展厅、库房和设备成为剩余空间 | 删除造型语言后，功能和剖面逻辑是否仍成立？ |
| 只画一条漂亮参观线 | 忽略短线、逆行、高峰、无障碍和疏散 | 用儿童团体、老人、30分钟访客分别走一遍 |
| 常设/临展共用唯一运营边界 | 换展会牵连全馆 | 让临展闭展施工，常设展能否正常开放？ |
| 后勤只画货梯 | 全程最窄处决定运输成败 | 用最大包装体和搬运设备做三维扫掠 |
| 大厅/中庭过量 | 公共面积大却服务能力不足 | 按峰值排队、活动布置和闭馆分区实排 |
| 展厅只看面积 | 柱、门、风口切碎可展面 | 统计连续展墙并放入真实展项 |
| 可变展墙等于灵活展厅 | 机电、消防、灯光不能随之变化 | 改三种布局后逐项复核接口和疏散 |
| 自然光等于空间品质 | 光损伤、眩光与热负荷失控 | 以最敏感展品和最不利太阳时刻校验 |
| 先定层高再塞设备 | 净高、检修和结构冲突后置 | 在关键剖面叠合所有系统真实高度 |
| 利用高差等于做下沉 | 可能带来防水、绕行和方向混乱 | 比较台地、双首层、半下沉三案的收益与代价 |
| 用监控代替流线分离 | 安防系统不能消除物理交叉 | 标出任何观众与藏品共享门、电梯厅和走廊 |
| 疏散依赖展陈布局 | 换展后安全条件失效 | 移动所有可变展墙后复核出口可见与通达 |
