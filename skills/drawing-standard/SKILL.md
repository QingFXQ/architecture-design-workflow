# 建筑课程制图语言

按[制图生产流程](../../workflows/DRAWING_PRODUCTION_WORKFLOW.md)执行。图书馆特定要求见[图形档案](../../knowledge/practice-feedback/wuchang-library.graphic-profile.json)；正式图内字体／图名按项目要求，不机械采用旧默认值。

先核当前设计基准和要交的图，用相关工程样板试做并导出看图。已有用户授权下由当前主控直接制作、自检和修复，不要求独立角色交接或用户逐次Gate。下面是按图件选用的检查方法，不是每批全量执行的清单。

仓库列出的国标版本是既有参考入口，不代表本轮重新核实的现行适用结论；实际项目涉及规范判断时核官方有效版本和适用条件。项目图形偏好与法定要求分开。

## 1. 适用范围与规则优先级

本 Skill 用于建筑学课程设计阶段的总平面、建筑平面、立面、剖面及必要详图的生产与审查。

规则分为三级：

1. [任务书/教师要求]：项目已有明确要求时优先执行。
2. [国标]：采用现行建筑制图国家标准作为基础制图语言。
3. [课程默认]：任务书未规定时采用本 Skill 的课程设计默认值。

不得为了规范化擅自增加任务书未要求的施工图深度。

主要依据：GB/T 50001-2017《房屋建筑制图统一标准》、GB/T 50104-2010《建筑制图标准》、GB/T 50103-2010《总图制图标准》。

## 2. 总体制图原则

所有图纸必须首先满足：

- 图面清晰；
- 信息层级明确；
- 平、立、剖互相对应；
- 尺寸、轴线、标高能够互相校核；
- 比例与表达深度匹配；
- 不出现模型中存在但图纸无法解释的空间；
- 不使用渲染效果掩盖建筑关系；
- 不为丰富图面增加无设计意义的信息。

DrawingProduction 的目标是准确表达建筑方案。

## 3. 图线体系

### 3.1 国标原则

[国标] 图线应形成明确粗细等级。
GB/T 50001-2017 的基本线宽 b 根据比例和复杂程度从 1.4、1.0、0.7、0.5 mm 等系列选取。
打印成品必须能够明确区分主要轮廓、次要轮廓和辅助信息。

### 3.2 课程设计默认打印线宽

[课程默认，可修改] 建议 Revit 出图采用四级视觉层级：

| 视觉层级 | 建议打印线宽 |
| --- | --- |
| 剖切主体 | 0.50～0.70 mm |
| 主要可见轮廓 | 0.35～0.50 mm |
| 次要构件 | 0.25 mm |
| 尺寸、填充、家具、辅助信息 | 0.13～0.18 mm |

核心原则：被切到 > 看得到 > 辅助表达。
剖面中实际被剖切的承重柱、梁、板及承重墙按项目要求实心填黑，明显重于投影；普通填充墙、玻璃、门窗不统一黑填。剖切厚度与实际构件对应，不以通长粗黑横线代替空间。
家具、铺地、绿化等不得抢过建筑主体。

Revit 侧的具体落地（对象样式到线宽号的四档映射、线宽表随比例变化、轴网线型、家具必须靠视图过滤器或族内子类别才能细分）见 [`../revit-model-hardening/references/graphic-hierarchy-revit.md`](../revit-model-hardening/references/graphic-hierarchy-revit.md)。

## 4. 字体与文字

[国标] 同一张图纸字体种类原则上不超过两种；拉丁字母和数字打印字高不得小于 2.5 mm。

[课程默认] 推荐打印字高：

| 文字类型 | 推荐打印字高 |
| --- | --- |
| 总标题 | 7～10 mm |
| 图名 | 5～7 mm |
| 房间名称 | 3.5～5 mm |
| 普通说明 | 3.5 mm |
| 标高、轴号、尺寸 | 2.5～3.5 mm |

图纸内部标注和图名采用项目指定字体；本用户图书馆采用仿宋，展板大标题可另设协调字体。缩小图件后按最终纸面重设图内字高，不只改图名。

整套图纸保持统一字体体系。
禁止为了排版同时混用大量字体、粗细和字号。

## 5. 比例

[国标] 建筑平面、立面、剖面常用 1:50 / 1:100 / 1:150 / 1:200 / 1:300。
局部放大图 1:10 / 1:20 / 1:25 / 1:30 / 1:50。
详图根据表达对象可进一步放大。
一个图样原则上使用一种比例，图名写“xxx图  1:n”。项目要求时图名下画上细下粗双横线。各层用首层／二层／三层／四层／顶层平面图等明确名称；地下层另列。横向尺寸置图下方，标高用标准符号而不是单根线段。

[课程默认] 一般课程设计建议：

| 图纸类型 | 建议比例 |
| --- | --- |
| 总平面 | 1:500（大基地 1:1000） |
| 建筑平面 | 1:100 / 1:200 |
| 立面 | 1:100 / 1:200 |
| 剖面 | 1:100 / 1:200 |
| 重点空间 | 1:50 |
| 构造或节点 | 1:10～1:50 |

总图国家标准允许总平面采用 1:300、1:500、1:1000、1:2000 等比例。

## 6. 定位轴线

[国标] 定位轴线采用细单点长画线。
一般矩形建筑：水平方向阿拉伯数字从左向右编号；垂直方向大写英文字母从下向上编号。
I、O、Z 不作为普通轴号使用。
轴号圆宜为 8～10 mm。
同一套图纸轴号必须完全一致。
平面、立面、剖面之间不得出现轴号错位。

## 7. 总平面图

总平面应至少表达：

- 用地边界；
- 建筑轮廓；
- 建筑主要出入口；
- 场地主要出入口；
- 道路及主要步行系统；
- 必要的广场和室外空间；
- 建筑层数或高度；
- 指北针；
- 图名及比例；
- 关键定位尺寸或坐标；
- 必要室外标高；
- 与设计有关的现状建筑、道路、环境条件。

需要时增加：停车；消防通行；景观；水体；高差处理；场地剖切位置。
总图原则上上北下南；因基地形状可以适当旋转，但必须设置指北针或风玫瑰。
总平面国家标准通常以米作为坐标、距离和标高单位。
课程设计中不得把总平面退化为单纯的建筑屋顶轮廓图。

## 8. 建筑平面图

建筑平面采用水平剖切后向下投影的表达方式，应表达剖切面以及投影方向可见的必要建筑构造。
房间应标注名称或编号。

每层平面至少检查：

- 墙、柱及主要结构位置；
- 门窗；
- 楼梯、坡道、电梯；
- 房间名称；
- 主要家具或设备；
- 卫生间基本布置；
- 轴网；
- 必要尺寸；
- 标高；
- 剖切符号；
- 出入口；
- 高差；
- 上空、挑空等特殊空间；
- 与设计有关的虚线投影。

±0.000 所在主要平面应设置指北针，其方向必须与总图一致。
家具用于证明空间尺度和使用逻辑，不用于装饰图纸。

## 9. 平面尺寸

尺寸应根据设计深度至少覆盖：

1. 建筑总体尺寸；
2. 主要轴线定位尺寸；
3. 关键空间、洞口或构件尺寸。

GB/T 50001-2017 要求尺寸线与尺寸界线采用细实线，图样本身的轮廓线不得直接充当尺寸线。
课程设计阶段优先保证：建筑能定位、空间能判断、设计能复核。
禁止大量重复尺寸导致图面失去层级。

## 10. 立面图

立面采用正投影表达。
必须表达：

- 建筑外轮廓；
- 门窗及主要开口；
- 墙面凹凸关系；
- 雨棚、檐口、栏杆等主要构件；
- 地坪线；
- 必要轴号；
- 主要高度或标高；
- 重要材料或表面处理。

国家标准要求建筑立面表达投影方向可见的建筑外轮廓、墙面线脚、构配件、墙面做法及必要尺寸和标高。
立面应与平面真实对应。
不得为了立面效果擅自移动平面门窗。

## 11. 剖面图

剖切位置必须具有设计信息价值。
优先选择经过：主要公共空间；楼梯；中庭；通高空间；高差变化；屋顶变化；重要空间组合关系。
国家标准要求剖面选择能够反映建筑全貌、构造特征或具有代表性的部位，并表达剖切面、投影可见构件及必要尺寸和标高。

剖面必须表达：

- 室外地坪；
- 各层楼地面；
- 楼板；
- 屋面；
- 墙柱；
- 门窗洞口；
- 楼梯；
- 主要空间高度；
- ±0.000；
- 层高；
- 建筑总高度或关键高度。

剖面应重点证明建筑空间关系，而不能只作为高度版立面。

## 12. 标高

[国标] 建筑标高以米为单位。
零点 ±0.000；正标高 3.600；负标高 -0.600。
一般建筑标高注至小数点后三位。
总平面室外标高根据总图规则通常可表达至小数点后两位。
平面、立面、剖面的同一位置标高必须一致。

## 13. 表达深度

课程设计图纸必须遵守：比例越大，表达信息越多。
GB/T 50104-2010 明确允许随着比例缩小逐渐省略抹灰层、保温层、材料图例及部分面层；1:100～1:200 可采用简化材料表达。
因此不得要求 1:200 课程设计平面达到 1:20 施工详图的信息密度。

## 14. 平立剖一致性检查

DrawingProduction 每次出图后必须进行自动交叉检查。

### 几何一致性

- 平面门窗位置 = 立面门窗位置；
- 平面楼梯 = 剖面楼梯；
- 平面墙柱 = 剖面墙柱；
- 建筑层数一致；
- 屋顶形态一致。

### 高程一致性

- ±0.000 一致；
- 层高一致；
- 楼板位置一致；
- 屋顶高度一致；
- 室内外高差一致。

### 编号一致性

- 轴号一致；
- 图名一致；
- 剖切编号一致；
- 房间名称一致。

出现冲突时禁止静默修改。
必须返回：`DRAWING_CONFLICT`，并说明冲突位置及可能来源。

## 15. 出图前 Final Check

每张正式图纸至少检查：

- [ ] 图名
- [ ] 比例
- [ ] 图线层级
- [ ] 字体可读
- [ ] 轴网
- [ ] 尺寸
- [ ] 标高
- [ ] 剖切符号
- [ ] 指北针（需要时）
- [ ] 房间名称
- [ ] 门窗
- [ ] 楼梯/电梯/坡道
- [ ] 平立剖一致
- [ ] 无文字重叠
- [ ] 无尺寸重叠
- [ ] 无裁切遗漏
- [ ] 无模型辅助线泄漏
- [ ] 黑白打印后仍具有清晰层级

关键缺陷修复并复核后才标为当前有效图件；未受影响检查可复用。内部检查不是新增人工审批。
