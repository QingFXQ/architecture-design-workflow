# 方案规范自查

将本 Skill 用于方案深化阶段的专业判断。

它用于识别明显风险、说明依据、提出尽量小的修改方向。

它不生成执业审图结论。

它不替代注册建筑师、专项顾问、消防审查或当地主管部门。

LLM 阅读方案、规范笔记及原文，解释适用条件；允许用可复核工具计算几何、面积、距离、净宽、人数和容量。每项计算记录输入版本、单位、规则来源、适用前提、过程和误差限制，不能让未核实规则或计算结果自动裁定整栋合规。项目、地区或条文适用性未确定时，只报告条件性结果与待核问题。

执行[方案设计与画图的共同检查约定](../../workflows/SCHEME_DRAWING_REVIEW.md)中的面积、容量及变更复查约定；风险修正也应保持已确认的空间与审美意图。

## 工作位置

服务对象是 当前主控。

使用时点是形成可实施方案、提交 当前方案基准 比较包之前。

上游是 已确认概念 已选概念、任务书、场地和用户约束。

下游是更新后的方案确认包与 当前方案基准。


## 五段契约

### Required Input

必须接收当前方案确认包或足以形成方案确认包的深化材料。

必须接收场地资料。

必须接收建筑类型和使用性质。

必须接收项目所在地、适用地区或明确标注“地区待确认”。

必须接收总图。

必须接收各层平面。

必须接收至少一个关键剖面或层高说明。

必须接收建筑面积、层数、建筑高度和地下/半地下情况。

必须接收主要功能、容量或预计人流。

必须接收已知消防、无障碍、日照或特殊运营条件。

必须接收方案版本与相关决策 ID。

若属于博物馆、幼儿园、中小学或混合类型，必须接收对应的功能规模资料。

若用户提供规范 PDF，必须接收其文件、适用版本和来源说明。

### Required Output

输出规范风险清单。

输出每个风险涉及的规范条文。

输出每个风险的影响。

输出每个风险的修改建议。

输出检查范围、资料缺口和适用条件。

输出阻断性风险、需深化风险和待专业复核项的分类。

输出所读取的 research/building-codes 笔记和用户提供 PDF 的引用。

输出与方案确认包对应的版本号。

不得把“未发现”写成“已完全合规”。

### Exit Criteria

无未解决的阻断性风险。

每个已识别风险均有依据、影响和可执行的下一步。

适用建筑类型的关键主题已经覆盖。

资料不足项已公开标注为待专业复核。

方案修改后已对受影响主题复查。

检查记录可随方案确认包被 当前方案基准 审阅。

### Return Conditions

发现关键规范冲突时，返回方案深化。

发现会动摇总图、体量、层数、核心流线或剖面关系的问题时，返回方案变体或关键剖面。

缺少建筑类型、所在地、层高、人数或关键图纸时，返回 当前主控 补充资料。

发现需要地方标准、专项计算或原文 PDF 才能判断时，返回待专业复核，不作猜测性通过。

发现方案本身不可行时，不将其描述为 Drawing 的制图错误。

### Next

通过后，检查记录随方案确认包进入 当前方案基准。

当前方案基准 前的方案修改仍由 当前主控 负责。

用户批准方案后，确认包才可交给 Drawing Production Agent。

需要记录风险状态或用户决定时，交由 Director。

## 先做输入完整性判断

读取当前 Scheme Issue。

读取 已确认概念 的已选概念和必须保留的设计意图。

读取 `PROJECT.md`、`BRIEF.md`、`DECISIONS.md` 与 `DESIGN_THESIS.md`。

读取总图、平面、剖面、流线、体量参考和面积表。

核对方案版本是否一致。

核对用户修改意见是否已纳入图纸。

核对场地红线、道路、相邻建筑、标高和朝向是否明确。

缺失资料时先列出“无法判断的原因”。

不要用常见尺寸填补关键缺失。

不要因图纸看起来完整而假定地方条件已满足。


## 规范资料读取顺序

先读取与问题直接相关的项目笔记。

将笔记定位为方案阶段的索引与风险提示。

涉及精确边界、版本冲突或审批结论时，读取用户提供的原文 PDF。

原文 PDF 不可读或页码不清时，明确说明无法可靠引用。

不要杜撰 PDF 页码、条文号或版本。

不要把笔记中的“常见做法”当成强制条文。

不要忽略笔记末尾的“不确定/待核实条目”。

当通用规范与专用规范同时适用时，比较适用条件并采取较严格的已确认要求。

当国家规范与地方文件同时适用时，提示地方文件可能更严。

当标准已被新通用规范部分覆盖时，先核对新的强制性通用规范。

保留引用的文件名、规范编号、版本和条文号。

记录引用来自笔记还是原文 PDF。

记录引用适用的建筑类型、层数、高度、人数或地区前提。

## 判断方法

从总图开始识别场地和到达风险。

再从平面识别功能、疏散和无障碍风险。

再从剖面识别层数、层高、楼梯和日照风险。

最后从建筑类型识别专用规范风险。

将图纸、文字说明和模型草图相互核对。

优先核对会迫使体量或平面重构的问题。

再核对可以通过局部调整解决的问题。

当信息互相矛盾时，标注矛盾而不是自行选一份为真。

当尺度难以从图上可靠读取时，要求标注尺寸或源模型信息。

当风险依赖实际人数时，使用方案给定人数。

如人数仅是估计，说明估计来源和不确定性。

公式与程序可以复核已确认前提下的数值，不得省略适用性判断而批量宣布合规。

可用手工、图纸、模型或数值工具测量空间关系，保存可复跑的输入与结果。

结论必须解释“为什么当前方案会触发该问题”。


## 风险级别

将会阻止方案继续进入 当前方案基准 的问题标为“阻断”。

将会显著影响安全、法定底线或核心空间关系的问题优先标为“阻断”。

将当前图纸明显不满足已确认条文的问题标为“需修改”。

将资料不足、地方标准未取得或需要专项计算的问题标为“待专业复核”。

将合理但尚未证实的关注点标为“观察项”。

不要用“观察项”弱化已经明确的冲突。

不要以“可能可以性能化”消除阻断项。

性能化、消防专项或日照专项只改变下一步的核实路径，不自动等于通过。


## 每个风险点的固定格式

按以下四项输出每个风险点。

### 风险描述

写明当前方案的具体位置、对象和触发条件。

说明是图纸明确显示、资料缺失，还是方案推定。

说明风险级别。

### 涉及规范条文

引用 `research/building-codes` 的具体文件与章节。

必要时引用用户提供 PDF 的规范编号、条文号、页码或页签。

同时写明条文的适用前提。

### 影响

说明影响的是生命安全、通行、公平使用、采光、运营、文物保护或审批风险。

说明会影响总图、平面、剖面、体量、流线还是局部构件。

说明不处理可能阻断的后续 Gate。

### 修改建议

提出保持已批准设计意图的最小可行调整。

给出需要重画或重核的图纸范围。

说明调整后必须复查的主题。

不能确定具体尺寸时，建议取得原文 PDF、地方要求或专业意见。


## 防火与疏散自查

核对建筑类型、耐火等级、建筑高度、层数和地下空间。

核对每个防火分区的边界是否清晰。

核对防火分区面积是否与适用条件相符。

核对地下和半地下部分是否按更严条件单独理解。

核对防火墙、分隔墙、门和卷帘是否与分区意图一致。

核对主要空间是否跨越未经处理的防火分区。

核对每个防火分区的安全出口数量和分散关系。

核对房间门至安全出口的可达路径，而非仅看直线视觉距离。

核对袋形走道是否被误作普通走道。

核对走道、楼梯和首层外门的净宽是否有明确依据。

核对楼梯间形式与建筑类型及高度是否匹配。

核对地下楼梯与地上楼梯的分隔关系。

核对消防电梯、前室、避难层或救援口是否因建筑高度被触发。

核对消防车道、救援场地与建筑外墙的关系。

核对疏散门开启方向、出口落点和室外安全疏散方向。

不把图上有两部楼梯自动判作“两部有效疏散楼梯”。

不把 Revit、MCP 或其他工具的成功返回当作疏散正确。


## 楼梯、走道与临空防护自查

核对梯段数量、起终点和跨层连接。

核对踏步高宽、平台宽度和净宽。

核对楼梯是否被梁、门扇、设备或栏杆侵占净宽。

核对平台是否被开向平台的门压缩。

核对扶手高度、连续性和儿童/无障碍双层扶手需求。

核对楼梯井、栏杆竖杆间距和禁止攀爬要求。

核对临空栏杆高度与建筑高度、儿童使用场景相符。

核对落地窗、低窗台、外廊和屋面边缘的防坠落关系。

核对走道净高是否被梁、吊顶或设备压低。

核对公共建筑、学校或幼儿园专用走道要求是否比通用要求更严。


## 无障碍自查

核对主要到达路径能否连续连接公共道路、停车、场地、入口和主要公共空间。

核对主要出入口是否有无障碍入口，而不是仅有后勤坡道。

核对坡道的坡度、净宽、平台、扶手和转弯空间。

核对门洞净宽、门前平台和开门后的轮椅通行。

核对走道转弯、候梯厅和主要房间前的轮椅回转空间。

核对多层公共建筑的无障碍电梯是否被触发。

核对电梯轿厢、门宽和候梯厅是否服务真实路径。

核对无障碍卫生间或厕位的位置、门向和使用空间。

核对无障碍停车位、低位服务设施、轮椅席位和标识是否因建筑类型被触发。

发现仅靠“可以搬运”或“有人协助”才能通行时，视为无障碍风险。


## 日照、采光与空间尺度自查

先确认城市、气候区、当地日照文件和分析软件要求。

核对相邻现状、在建和已批未建建筑是否可能造成遮挡。

核对日照控制对象是住宅、学校、幼儿园、老年照料还是其他空间。

核对日照时段、计算窗口和达标房间数量。

对幼儿园活动室与寝室重点核对冬至日满窗日照。

对中小学普通教室重点核对冬至日满窗日照和达标教室数量。

对住宅重点核对居住空间与相邻遮挡。

日照只能用草图或经验预估时，明确写为“需专项日照复核”。

核对窗地比、朝向、净高、层高和关键房间短边。

核对地下、半地下和无自然采光空间的使用限制。

核对房间面积是否与功能人数、家具和疏散路径能同时成立。

不要以漂亮的渲染光影替代日照或采光判断。


## 建筑类型专项自查

### 博物馆

核对藏品区、陈列区与观众服务区是否严格分区。

核对藏品库、缓冲、修复和后勤的独立流线。

核对库房是否被安排在不利防潮的位置或被给排水管道穿越。

核对库房与展厅的净高、面积比例和温湿度控制前提。

核对展厅与藏品区是否存在不当直接连通。

核对展厅主通道、观众服务、报告厅、安检和无障碍需求。

核对文物保护、安防和消防要求是否会改变核心空间边界。


### 图书馆

核对书库与其他部位之间是否有防火墙**和**甲级防火门，两者是否成对存在。

核对阅览室窗地面积比是否达到 1/5，且按洞口面积而非建筑面积计算。

核对阅览室与走廊、书库、设备用房之间的隔声量是否满足允许噪声级 40 dB(A)。

核对书库楼面荷载是否按常规架与密集架分别取值。

核对藏书量、阅览座位数与面积三者是否互相自洽；用册数密度与每座面积反推，不用图纸量算。

核对借阅动线：门厅 → 出纳 → 开架书库 → 阅览，是否在最短路径内闭合。

核对夜间独立使用区域是否有独立交通核与独立出入口，闭馆后能否只开这一段。

核对采编、卸货、书刊货梯与藏书室的垂直动线是否不穿越公共区。

核对恒温恒湿区（善本、珍本、藏书室）是否避光、避外墙、避给排水管道穿越。

核对报告厅的视线、声学、独立疏散与控制室位置。

核对项目是否属于强制绿色建筑星级范围，以及由此反推的围护结构热工与窗墙比要求。

图书馆专项条文、地方规定、墙体厚度四约束、采光与隔声核算方法见 [`research/building-codes/08-library.md`](../../research/building-codes/08-library.md)。


### 幼儿园

核对班额、班级活动单元和每班独立卫生间。

核对活动室、寝室、音体活动室、保健观察室和厨房的面积与净高。

核对层数和儿童生活用房的分层安排。

核对儿童楼梯踏步、双层扶手、栏杆、窗台和防夹门要求。

核对生活用房防火分区、疏散距离、安全出口和封闭楼梯间。

核对室外活动场地、班级专用场地、人均面积和机动车隔离。

核对冬至日满窗日照是否影响活动室、寝室或活动场地。


### 中小学校

核对班额、普通教室面积、净高、短边和采光方向。

核对教学楼层数、内外廊宽度、楼梯和双层扶手。

核对教学用房、专用教室、卫生间、饮水处和运动场地。

核对临空窗台、栏杆、门型和学生安全防护。

核对教学楼日照、与道路或运动场的关系和无障碍电梯。

核对疏散出口、距离、走道和楼梯能否服务实际班级人数。


## 修改建议的边界

先提出不会改变 已确认概念 核心命题的局部调整。

例如，调整楼梯位置、增加出口、重组服务带或细化防火分隔。

例如，调整层高、走道宽度、坡道路径、门窗基本位置或房间比例。

当局部调整不足以解决问题时，明确说明必须重新比较体量、总图或剖面。

不得为了满足局部条文，悄悄删除用户已批准的关键空间体验。

不得把未获批准的设计重构当成“规范修正”。

将方案选择的代价和收益交回 当前主控 与用户判断。


## 复查与交接

方案修改后，先确认修改影响哪些风险点。

重新读取被修改的总图、平面、剖面和说明。

重新检查所有受影响的防火、无障碍、日照和专项要求。

更新风险状态为“已解决”“仍阻断”“待复核”或“新增风险”。

保留旧版本的风险记录，不覆盖历史判断。

将阻断性风险、待专业复核和未冻结项放入方案确认包。
