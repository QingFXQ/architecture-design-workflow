# 项目工作日志模板

复制到项目根目录，命名为 `PROJECT_LOG.md`。

## 使用规则

1. **只追加，不改写历史。** 新条目写在最上面或最下面，选定一种并保持一致；推荐“最新在上”。
2. **日志不是第二个状态源。** 当前阶段/Gate/版本仍写在 `PROJECT.md`；日志只记录“什么时候、谁、做了什么、证据是什么、偏差是什么”。
3. **一次工作会话一条。** 同一天多次会话可合并，但必须保留日期和顺序。
4. **每条都要有证据。** 文件、commit、日志、截图、hash、用户原话，至少一个。
5. **决策进 `DECISIONS.md`。** 日志只引用决策 ID，不复制完整决策表。
6. **产物进 `ARTIFACTS.md`。** 日志只写“生成了什么/改了哪个版本”，不复制完整清单。
7. **不把 AI 建议写成用户决定。** 用户没说的，标“建议/待确认”。

## 条目模板

```markdown
## YYYY-MM-DD｜[阶段/Issue] [一句话标题]

- 会话/执行器：
- 阶段 / Gate：
- 设计版本：
- 用户输入（原话或摘要）：
- 本轮意图：
- 做了什么：
- 产物（路径 / 版本 / hash）：
- 证据（日志 / 截图 / 回读 / 测试）：
- 决策（引用 `DECISIONS.md` ID）：
- 偏差 / 返工：
- 未闭合 / 风险：
- 下一步（唯一）：
- 是否改变 Gate 状态：否 / 是（写明）
```

## 示例

```markdown
## 2026-10-19｜Scheme / 整体旋转

- 会话/执行器：DSH / lead
- 阶段 / Gate：Scheme，Gate B 未通过
- 设计版本：SD-v1.1-WIP-UNIFIED-rotation
- 用户输入：要求两体量整体旋转，主体长边竖向，重排临湖/主次入口/交通/后勤
- 本轮意图：在保持 135° 与尺寸的前提下，把旧总平定位退出推荐
- 做了什么：旋转上部 2,836 个构件；回读 123 个 Room；重排首层入口/后勤；做 B1 矩形研究
- 产物：`1.rvt`（42,442,752 bytes，22:56）；`图书馆方案图册.pdf`（33 页，22:56）
- 证据：`.revit-work/logs/UNIFIED_rotation_upper_measurement_latest_native_check.json`
- 决策：D-009、D-010
- 偏差 / 返工：B1 矩形候选 7,790㎡ 临建后撤回；12/486 探针冲突待修
- 未闭合 / 风险：场地红线、B1 容量、结构、消防、功能缺口
- 下一步：按 Gate B 12 项清单标 blocking / known-unknown
- 是否改变 Gate 状态：否
```

## 与其他文件的分工

| 文件 | 回答的问题 | 更新方式 |
|---|---|---|
| `PROJECT.md` | 现在到哪了？ | 每次状态变化覆盖 |
| `DECISIONS.md` | 用户决定了什么？ | 只追加，旧决定标替代 |
| `ARTIFACTS.md` | 有哪些版本？ | 滚动更新 + 历史保留 |
| `NEXT.md` | 唯一下一步是什么？ | 每次收束覆盖 |
| `PROJECT_LOG.md` | 为什么走到这里？ | 只追加 |
| `GATE_B_PACKAGE.md` | 能否提交 Gate B？ | 每次 Gate B 前重建 |

## 收束检查

- 最后一条日志的“下一步”是否与 `NEXT.md` 一致？
- 最后一条日志的“设计版本”是否与 `PROJECT.md` 一致？
- 本轮产生的决策是否都进了 `DECISIONS.md`？
- 本轮产生的文件是否都进了 `ARTIFACTS.md`？
- 有没有把“建议”写成“用户决定”？
