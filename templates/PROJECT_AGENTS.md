# 项目执行入口模板

新项目可将下面内容写入项目根目录的AGENTS.md，并将工作流仓库路径替换为实际位置。已有AGENTS.md时只合并本段，不覆盖用户原指令、CodeGraph规则或软件约束。

```markdown
# 建筑项目工作方式

- 工作流仓库：[填写真实绝对路径或项目内相对路径]。
- 先读当前PROJECT.md、BRIEF.md和最新反馈；已有模型从最新断点接续。
- 主线采用工作流仓库workflows/PIPELINE_WORKFLOW.md；当前主控直接研究、设计、建模、制图、看图修复和出PDF，不默认六角色或四次人工Gate接力。
- 概念／方案先用Blender或SU可编辑模型，真实截图后再AI预览；固定主要尺寸和场地后，在Revit或CAD制作标准建筑图。
- 操作前按工作流仓库docs/SKILL_LIBRARY.md和工程资产索引取当前任务方法／样板。重要批次对象回读与完整图面一起核；发现可复用问题更新原skill及样例，不只放项目补丁。
- 工程模型导出Blender后可继续立面与场地设计，变化同步受影响图纸；先排版参考与纸面预案，再制作分析图，最后同版排版PDF。
- 用户指定纸幅、字体、命名、精度与冻结项写BRIEF；不从别的项目复制学生信息或精确指标。
- 模型、缓存和临时文件使用用户指定磁盘；项目源文件和交付跟随项目。一个活动文档一个写入者，超时先查状态不重放。
- 用户授权连续制作时自行检查并推进，不把普通可恢复动作逐项交用户审批；关键未决项集中说明，单项故障先做独立工作。
```
